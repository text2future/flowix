# AI 模型区域上线核对

模型目录按账号的 `region` 匹配 AI 服务商的 `market_region`。迁移 `0015_ai_provider_market_region.sql` 会将已有服务商默认设为 `non_mainland`，不能根据服务商名称自动判断服务合同或市场区域。

部署区域筛选前，在目标环境的后台逐一核对 AI 服务商区域；属于大陆市场的服务商设置为 `mainland`，其他设置为 `non_mainland`。核对两种账号分别能看到预期模型，并确认每个区域至少有一个已启用、定价完整的模型。区域没有可用模型时，登录账号的 Cloud 模型列表为空。

访客预览目录不带账号区域；模型请求本身目前也不校验区域，此规则仅用于登录后的模型目录。
