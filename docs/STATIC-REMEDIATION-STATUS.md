## 尚未认定解决

1. **跨进程 TOCTOU**：其他程序仍可能在检查后替换目录、链接或文件。哈希复核缩小了窗口，但最终复核与提交不是对任意外部写入者的原子 CAS。彻底修复需要跨平台基于目录/文件句柄的受限 I/O 和对应平台验证。
2. **IPC 传输内存**：正常原生文件上传已改为有界分块，旧完整 Base64 命令已移除。但 Tauri 在命令开始执行前仍可能持有完整请求字符串；应用层块大小限制不是传输层请求体上限。
3. **已提交任务的取消**：分块会话支持取消、到期回收和窗口关闭清理；最终发布开始后仍不承诺撤销。后端事前记录降低前端崩溃后丢失线索的风险，但记录、文件和编辑器插入不是同一个事务。
4. **孤立文件清理**：已有跨注册笔记本的已保存 asset URL 扫描接口；未保存编辑、撤销栈及其他引用语法不在完整覆盖范围。没有自动回收和恢复管理 UI；所有扫描结果均不授权删除。
5. **事件全序**：普通保存和版本恢复已用写锁内 receipt 关联快照与 revision，前端增加乱序防护；但其他写入入口、派生索引、版本记录及跨窗口事件仍不是一个事务，也没有持久队列和崩溃重放。
6. **权限边界**：窗口隔离仅针对明确授予的单文件权限；注册笔记本和启用的资料目录仍是应用级可信目录。独立文档窗口不得自动继承其他窗口的外部文件权限，需要在目标窗口重新选择文件。
7. **平台与回归**：Windows reparse point、macOS 书签、原生对话框以及多窗口集成行为未运行验证。现有自动化测试也未执行。
8. **全项目覆盖**：已修复插件启动目录、未知权限降级及云认证/凭据清理中的确定问题；凭据仍明文存储，Windows ACL、全部运行时沙箱、同步并发场景及依赖漏洞尚未完成全面复核。
