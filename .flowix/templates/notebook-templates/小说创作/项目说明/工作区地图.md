# 工作区地图

> 一张图看懂本笔记本每个区域干什么、该往哪放。（配合 `命名规范.md`、`版本规则.md`）

## 顶层结构
```
小说创作/
├── AGENTS.md            # Agent 协作规范（给 AI 看）
├── README.md            # 人类使用手册
├── .agents/             # 技能 + 模板（引擎）
├── 小说设定/            # 世界事实与规则、时间线、术语、主题
├── 人物/                # 主要 / 次要人物、关系、当前状态
├── 大纲/                # 总纲、情节节点、章节总览、场景总览、待解决问题
├── 正文/                # 第一部 / 第二部 / 第三部、已删除片段
├── 修订/                # 修订总览、结构清单、连贯性、章节修订、读者反馈、定稿清单
├── 创作管理/            # 当前写作、创作周计划、创作复盘
├── 素材与研究/          # 灵感、研究资料、创作素材、参考作品
└── 项目说明/            # 工作区地图、命名规范、版本规则
```

## 各区域一句话

| 区域 | 放什么 | 不放什么 |
| --- | --- | --- |
| `小说设定/` | 世界规则、时间线、术语、主题（最高一致性基准） | 具体情节 |
| `人物/` | 人物档案、关系、当前状态 | 正文 |
| `大纲/` | 结构蓝图：总纲 → 节点 → 章节 → 场景 | 成稿正文 |
| `正文/` | 正式章节稿 | 大纲、设定 |
| `修订/` | 修订清单、问题、反馈、润色记录 | 新写的正文 |
| `创作管理/` | 进度、周计划、复盘 | 创作内容本身 |
| `素材与研究/` | 灵感、研究、碎片素材、参考 | 定稿内容 |
| `项目说明/` | 规则说明 | 创作内容 |

## 创作主循环
```
故事构想 → 人物设计 → 大纲规划 → 场景设计
      → 章节续写（正文）→ 连贯性检查 → 结构修订 → 文字润色 → 创作复盘
```
