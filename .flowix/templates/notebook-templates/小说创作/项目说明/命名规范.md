# 命名规范 — 小说创作笔记本

所有路径与文件命名遵循本规范，保证 Agent 与人都好找、好写、好排序。

## 一、章节正文

```
正文/<部>/第NNN章-<标题>.md
```
- 章号：**全书连续**三位数（001、002…），不与部内重新编号。
- `<部>`：`第一部` / `第二部` / `第三部`。
- 示例：`正文/第一部/第001章-雾中来信.md`

## 二、人物档案

```
人物/主要人物/<姓名>.md
人物/次要人物/<姓名或称号>.md
```
- 示例：`人物/主要人物/林深.md`、`人物/次要人物/老周.md`
- 群像可合并：`人物/次要人物/群像-<类>.md`

## 三、大纲与设定（固定名）

```
大纲/故事总纲.md、情节节点.md、章节总览.md、场景总览.md、待解决问题.md
小说设定/小说总览.md、故事事实与规则.md、时间线.md、术语与命名.md、主题与母题.md
```

## 四、修订

```
修订/修订总览.md、结构修订清单.md、连贯性问题.md、读者反馈.md、定稿检查清单.md
修订/章节修订记录/第NNN章-<标题>.md
```

## 五、素材与研究

```
素材与研究/灵感收件箱.md、参考作品.md
素材与研究/研究资料/来源索引.md
素材与研究/研究资料/摘录/<主题>-<来源>.md
素材与研究/研究资料/事实核验/<事项>.md
素材与研究/创作素材/场景碎片/<关键词>.md
素材与研究/创作素材/对话碎片/<角色或主题>.md
素材与研究/创作素材/意象与描写/<意象>.md
素材与研究/创作素材/图片与地图/<用途>-<名称>.<ext>
```

## 六、创作管理（固定名）

```
创作管理/当前写作.md、创作周计划.md、创作复盘.md
```

## 七、内链约定

- 文档之间互相引用，统一使用**工作区相对路径**（从 `小说创作/` 起写），如 `小说设定/故事事实与规则.md`、`正文/第一部/第001章-雾中来信.md`。
- 好处：换设备 / 分享 / 迁移时链接不失效。

## 八、通用约定

- 正文一律 Markdown；二进制素材放 `素材与研究/创作素材/图片与地图/`，正文只放链接。
- 不删除历史（尤其正文与设定）；废弃内容移入 `正文/已删除片段/` 或标记归档。
- `<标题>` 不加标点，用词组，如 `雾中来信`。
