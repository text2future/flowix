# 小说创作笔记本 · 使用手册

欢迎使用「小说创作」笔记本。这是一套为长篇 / 系列小说准备的写作工作区：把设定、人物、大纲、正文、修订、素材分门别类，让几十万字的工程不再"写着写着就乱了"。适合网文作者、传统长篇作者，以及任何想认真完成一部小说的人。

## 一、这套空间能帮你做什么

- **设定不飘**：世界规则、术语、时间线统一放 `小说设定/`，写的时候随时查，前后不矛盾。
- **人物不崩**：每个角色的档案与当前状态都在 `人物/`，不会写着写着性格变了。
- **大纲可拆**：故事总纲 → 情节节点 → 章节 → 场景，一层层落到可动笔的颗粒度。
- **正文有序**：按部分卷，章节规范命名，多年后还找得到。
- **修订有痕**：连贯性问题、结构清单、润色记录都在 `修订/`，改稿不丢信息。
- **素材有池**：灵感、研究、场景碎片、对话碎片随手丢 `素材与研究/`，写时取材。

## 二、第一次上手（6 步）

1. 用「故事构想与定位」写 `小说设定/小说总览.md`、`主题与母题.md`、`故事事实与规则.md`。
2. 用「人物与关系设计」建主要人物档案与 `人物关系.md`。
3. 用「大纲与章节规划」写 `大纲/故事总纲.md`、`情节节点.md`、`章节总览.md`。
4. 用「场景设计与诊断」把关键章节细化成场景卡片。
5. 用「章节续写」在 `正文/第一部/` 开始写；每章写前先读设定与上一章。
6. 写完一批用「连贯性检查」→「结构修订」→「文字润色」，周期性地「创作复盘」。

## 三、目录地图


| 区域         | 放什么                                  |
| ---------- | ------------------------------------ |
| `小说设定/`    | 小说总览、故事事实与规则、时间线、术语与命名、主题与母题         |
| `人物/`      | 主要人物、次要人物、人物关系、当前人物状态                |
| `大纲/`      | 故事总纲、情节节点、章节总览、场景总览、待解决问题            |
| `正文/`      | 第一部 / 第二部 / 第三部 的章节正文、已删除片段          |
| `修订/`      | 修订总览、结构修订清单、连贯性问题、章节修订记录、读者反馈、定稿检查清单 |
| `创作管理/`    | 当前写作、创作周计划、创作复盘                      |
| `素材与研究/`   | 灵感收件箱、研究资料、创作素材、参考作品                 |
| `项目说明/`    | 工作区地图、命名规范、版本规则                      |
| `.agents/` | 技能与模板（AI 引擎）                         |


## 四、命名与版本约定

**命名**

- 章节正文：`正文/<部>/第NNN章-<标题>.md`（如 `正文/第二部/第013章-旧案重提.md`）。
- 人物档案：`人物/主要人物/<姓名>.md`。
- 修订记录：`修订/章节修订记录/第013章-旧案重提.md`。
- 内链统一用**工作区相对路径**（从 `小说创作/` 起，如 `小说设定/故事事实与规则.md`），换设备 / 分享不失效。

**版本**

- 改写重要情节前，先按 `项目说明/版本规则.md` 留痕（副本或 git commit）。
- 废弃的正文片段移入 `正文/已删除片段/`，不直接删除。

## 五、给 AI 用的说明

- 所有 Agent 协作规范见 `AGENTS.md`。
- 九个技能在 `.agents/skills/`：故事构想与定位、人物与关系设计、大纲与章节规划、场景设计与诊断、章节续写、连贯性检查、结构修订、文字润色、创作复盘。
- 七个模板在 `.agents/模板/`：小说总览、人物档案、章节、章节计划、场景卡片、修订总览、创作周计划。

## 六、重要提醒

- **一致性是长篇的命**：任何新内容都要先对齐 `小说设定/故事事实与规则.md`，冲突优先改新稿、慎改已定设定。
- 本模板中的示例小说《雾中来信》仅演示格式，请按你的真实作品替换。
