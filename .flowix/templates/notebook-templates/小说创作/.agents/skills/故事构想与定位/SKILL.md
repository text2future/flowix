# 故事构想与定位

## 触发条件
- 用户有一个模糊灵感或题材想法，需要评估与定位。
- 上游就绪：`素材与研究/灵感收件箱.md`、`参考作品.md`（可选）。

## 输入
- 用户的灵感 / 题材 / 参考作品
- `素材与研究/灵感收件箱.md`、`素材与研究/参考作品.md`

## 输出
- `小说设定/小说总览.md`（使用 `.agents/模板/小说总览.md`）
- `小说设定/主题与母题.md`
- `小说设定/故事事实与规则.md`（世界的硬规则，供全流程对齐）

## 工作流
1. 提炼一句话故事（logline）、题材类型、目标读者。
2. 明确主题与母题（这个故事到底在讲什么）。
3. 定义卖点 / 钩子与整体基调（文风、节奏）。
4. 写清世界观的事实与规则（含"绝对不成立"的红线）。
5. 产出三份文档，作为后续一致性的基准。

## 质量检查清单
- [ ] logline 一句话说清"谁、想要什么、阻碍是什么"
- [ ] 主题明确，能贯穿全书
- [ ] 卖点 / 钩子清晰，有读者吸引力
- [ ] 事实与规则完整，含红线（禁止项）
- [ ] 已落到 `小说设定/` 三份文档

- 下游：`人物与关系设计`、`大纲与章节规划`
