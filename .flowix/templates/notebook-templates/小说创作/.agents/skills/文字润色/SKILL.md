# 文字润色

## 触发条件
- 结构定稿后做句层优化，或用户指定某段润色。
- 上游就绪：`结构修订` 已完成（情节不再大幅变动）。

## 输入
- `正文/` 待润色章节
- `小说设定/术语与命名.md`（用词统一）
- `素材与研究/创作素材/意象与描写/`（可取材）

## 输出
- 润色后的 `正文/<部>/<章节>.md`
- `修订/章节修订记录/<章节>.md`（记本次改了哪些维度）

## 工作流
1. 逐句看：是否啰嗦、重复、语感呆板、视角漂移。
2. 优化描写与对白（少形容词堆砌，多动作与细节）。
3. 统一术语与称谓（对照 `术语与命名.md`）。
4. 记录润色维度到 `章节修订记录/`。
5. **不改情节**；发现情节问题回交「结构修订」。

## 质量检查清单
- [ ] 未改动情节（只改表达）
- [ ] 术语 / 称谓统一
- [ ] 视角与基调保持一致
- [ ] 冗余 / 陈词滥调已清理
- [ ] 已写 `章节修订记录/`

## 上游 / 下游
- 上游：`结构修订`
- 下游：`定稿检查清单`、`创作复盘`
