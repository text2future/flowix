# 人物与关系设计

## 触发条件
- 需要创建 / 补全人物，或梳理人物关系。
- 上游就绪：`小说设定/小说总览.md`、`主题与母题.md` 已定。

## 输入
- `小说设定/小说总览.md`、`主题与母题.md`
- 用户对人物的设想
- 已有 `人物/主要人物/`、`人物关系.md`

## 输出
- `人物/主要人物/<姓名>.md`、`人物/次要人物/<姓名>.md`（使用 `.agents/模板/人物档案.md`）
- `人物/人物关系.md`（关系网络）
- `人物/当前人物状态.md`（随剧情更新的状态快照）

## 工作流
1. 为每个人物写：欲望 / 恐惧 / 缺陷 / 弧光（成长或堕落）。
2. 定义人物间关系（亲疏、利益、秘密、张力）。
3. 维护 `当前人物状态.md`：所在地、处境、知道什么、不知道什么。
4. 检查人物是否服务于主题与情节（不是孤立的设定堆砌）。

## 质量检查清单
- [ ] 主角有明确欲望与缺陷，且有弧光
- [ ] 人物关系有张力与变化可能
- [ ] 每个主要人物都服务于主题 / 情节
- [ ] `当前人物状态.md` 与正文一致
- [ ] 档案命名与内链符合 `项目说明/命名规范.md`

## 上游 / 下游
- 上游：`故事构想与定位`
- 下游：`大纲与章节规划`、`章节续写`（写作前查状态）
