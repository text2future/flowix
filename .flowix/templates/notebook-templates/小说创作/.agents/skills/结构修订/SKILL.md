# 结构修订

## 触发条件
- 读者反馈或自评发现结构 / 节奏 / 张力问题。
- 上游就绪：`修订/连贯性问题.md`、`读者反馈.md`。

## 输入
- `大纲/` 各文件、`正文/` 相关章节
- `修订/连贯性问题.md`、`读者反馈.md`

## 输出
- `修订/结构修订清单.md`（逐条：位置、问题、动作、优先级、状态）
- `修订/修订总览.md`（整体修订进度）
- 相关正文修订（按清单执行，重要改动先按 `项目说明/版本规则.md` 留痕）

## 工作流
1. 归纳结构与节奏问题（开头是否抓人、中段是否拖、高潮是否有力）。
2. 决定动作：删 / 并 / 调序 / 补线 / 加冲突。
3. 逐条写入 `结构修订清单.md`，排优先级。
4. 执行修订，更新修订总览；废弃片段移入 `正文/已删除片段/`。

## 质量检查清单
- [ ] 问题归纳到结构 / 节奏层面（非句层）
- [ ] 每条有明确动作与优先级
- [ ] 改动前已按版本规则留痕
- [ ] 修订总览与新稿同步更新
- [ ] 删减内容进 `已删除片段/` 而非删除

## 上游 / 下游
- 上游：`连贯性检查`、`读者反馈`
- 下游：`文字润色`、`创作复盘`
