# 章节续写

## 触发条件
- 用户要求写 / 续写某章正文。
- 上游就绪：`大纲/章节总览.md`、场景卡片、`人物/当前人物状态.md`、上一章正文。

## 输入
- `大纲/章节总览.md`（本章核心事件）、对应场景卡片
- `小说设定/故事事实与规则.md`、`术语与命名.md`（用词一致）
- `人物/当前人物状态.md` 与上一章正文（衔接）

## 输出
- `正文/<部>/第NNN章-<标题>.md`（使用 `.agents/模板/章节.md`）
- 更新 `人物/当前人物状态.md`（本章后的状态）
- 更新 `创作管理/当前写作.md`（写到哪了）

## 工作流
1. 先读：设定、术语、人物状态、上一章末尾、本章大纲。
2. 按场景卡顺序展开，守住视角与基调。
3. 写完自检：与设定是否矛盾、人物言行是否合理、是否达成本章事件。
4. 更新人物状态与当前写作。
5. **绝不**擅自改动已定大纲；需要改先与用户确认。

## 质量检查清单
- [ ] 本章达成大纲设定的核心事件
- [ ] 与设定 / 术语 / 人物状态无矛盾
- [ ] 与上一章衔接自然
- [ ] 视角一致，基调符合 `小说总览.md`
- [ ] 人物状态与当前写作已更新
- [ ] 命名符合 `正文/<部>/第NNN章-<标题>.md`

## 上游 / 下游
- 上游：`大纲与章节规划`、`场景设计与诊断`、`人物与关系设计`
- 下游：`连贯性检查`、`结构修订`、`文字润色`、`创作复盘`
