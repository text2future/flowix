# 大纲与章节规划

## 触发条件
- 需要从设定推进到写作蓝图。
- 上游就绪：`小说设定/` 与 `人物/` 已基本就位。

## 输入
- `小说设定/小说总览.md`、`故事事实与规则.md`、`主题与母题.md`
- `人物/主要人物/`、`人物关系.md`
- 已有 `大纲/` 文件

## 输出
- `大纲/故事总纲.md`（三幕 / 多幕结构、主线与副线）
- `大纲/情节节点.md`（关键转折、高潮、结局）
- `大纲/章节总览.md`（每章一行：章号-标题-核心事件-视角-状态）
- `大纲/待解决问题.md`（悬而未决的伏笔与坑）

## 工作流
1. 定主线（主角目标 + 阻碍）与副线。
2. 按幕 / 卷划分阶段，标出关键转折点（不可逆事件）。
3. 拆到章节粒度，写一句核心事件与视角。
4. 记录伏笔与待解决问题，避免"挖坑不填"。
5. 产出四份大纲文档。

## 质量检查清单
- [ ] 主线清晰，每幕有转折
- [ ] 章节总览每章都有推进（无注水章）
- [ ] 伏笔与待解决问题集中登记
- [ ] 大纲与人物弧光、主题一致
- [ ] 命名符合 `项目说明/命名规范.md`

## 上游 / 下游
- 上游：`故事构想与定位`、`人物与关系设计`
- 下游：`场景设计与诊断`、`章节续写`
