# 连贯性检查

## 触发条件
- 写完一批章节，需要通读检查一致性。
- 上游就绪：一批 `正文/` 章节 + `小说设定/`、`人物/`。

## 输入
- `正文/` 待检章节
- `小说设定/故事事实与规则.md`、`时间线.md`、`术语与命名.md`
- `人物/当前人物状态.md`、`大纲/待解决问题.md`（伏笔）

## 输出
- `修订/连贯性问题.md`（逐条记录：位置、问题、类型、建议）

## 工作流
1. 对照设定查：规则被违反？术语用错？
2. 对照时间线查：日期 / 季节 / 年龄 / 距离是否自洽。
3. 对照人物状态查：谁知道什么、伤口 / 道具 / 关系是否连续。
4. 对照待解决问题查：伏笔是否该回收。
5. 逐条记入 `修订/连贯性问题.md`，标注严重程度。

## 质量检查清单
- [ ] 覆盖设定 / 时间线 / 人物 / 伏笔四类
- [ ] 每条问题都标了位置与严重度
- [ ] 区分"必须改"与"可选优化"
- [ ] 不直接改正文（只记录，交后续修订）

## 上游 / 下游
- 上游：`章节续写`
- 下游：`结构修订`、`文字润色`
