# 创作复盘

## 触发条件
- 周期性（周 / 阶段）复盘，或写作卡壳需要复盘。
- 上游就绪：`创作管理/创作周计划.md`、`创作管理/当前写作.md`、`正文/` 进度。

## 输入
- `创作管理/创作周计划.md`（对照计划）
- `创作管理/当前写作.md`（进度与卡点）
- `修订/修订总览.md`（修订进度）
- `大纲/待解决问题.md`（伏笔进度）

## 输出
- `创作管理/创作复盘.md`（使用 `.agents/模板/创作周计划.md` 的复盘区，或独立成文）
- 调整 `创作管理/创作周计划.md` 与写作节奏
- 卡点归纳（分"情节 / 人物 / 语言 / 精力"）

## 工作流
1. 对照周计划看字数 / 章数达成。
2. 归纳卡点类型与原因。
3. 评估修订进度是否挤压写作。
4. 给出下阶段调整（走量 / 修稿 / 补大纲）。
5. 记录复盘，更新周计划。

## 质量检查清单
- [ ] 进度有数据（字数 / 章数），非感觉
- [ ] 卡点已归类并给出对策
- [ ] 修订与写作的精力分配已权衡
- [ ] 下阶段计划已明确
- [ ] 记录进 `创作管理/创作复盘.md`

## 上游 / 下游
- 上游：`章节续写`、`结构修订`、`文字润色`
- 下游：下一阶段创作计划
