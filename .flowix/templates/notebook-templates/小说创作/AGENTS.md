# AGENTS.md — 小说创作 工作区代理指南

本文件面向在本工作区运行的所有 AI Agent（智能体）。它定义了工作区的目的、结构约定，以及每个技能何时、如何被调用。人类用户请优先阅读 `README.md`。

## 一、工作区定位

这是一个**长篇小说创作笔记本**，用一套固定目录 + 一组专职 Agent 技能，把「构想 → 人物 → 大纲 → 场景 → 写作 → 连贯性检查 → 结构修订 → 润色 → 复盘」的全流程收敛到一个可复制、可追溯的空间里。

- 目标用户：长篇小说 / 中篇系列 / 网文作者，或需要系统化推进大部头创作的人。
- 核心资产：世界设定与规则、人物档案与关系、大纲与情节节点、正文、修订记录、素材与研究。
- 协作方式：每个技能只做一件事，上游产物是下游的输入；**小说设定（事实与规则）是所有创作共同遵守的标尺**（保证前后一致、不矛盾）。

## 二、目录结构与职责映射

| 目录 | 职责 | 主要协作技能 |
| --- | --- | --- |
| `小说设定/` | 总览、故事事实与规则、时间线、术语、主题（一致性的标尺） | 故事构想与定位 |
| `人物/` | 主要人物、次要人物、人物关系、当前状态 | 人物与关系设计 |
| `大纲/` | 故事总纲、情节节点、章节总览、场景总览、待解决问题 | 大纲与章节规划 / 场景设计与诊断 |
| `正文/` | 分部的章节正文、已删除片段 | 章节续写 / 文字润色 |
| `修订/` | 修订总览、结构清单、连贯性问题、章节修订、读者反馈、定稿清单 | 连贯性检查 / 结构修订 |
| `创作管理/` | 当前写作、创作周计划、创作复盘 | 创作复盘 |
| `素材与研究/` | 灵感收件箱、研究资料、创作素材、参考作品 | 故事构想与定位 / 章节续写 |
| `项目说明/` | 工作区地图、命名规范、版本规则 | — |

## 三、创作流水线（标准顺序）

**构思期**
1. **故事构想与定位** — 产出 `小说设定/小说总览.md`、`主题与母题.md`、`故事事实与规则.md`。
2. **人物与关系设计** — 产出 `人物/主要人物/`、`人物关系.md`、`当前人物状态.md`。
3. **大纲与章节规划** — 产出 `大纲/故事总纲.md`、`情节节点.md`、`章节总览.md`。
4. **场景设计与诊断** — 细化到 `大纲/场景总览.md` 与场景卡片，诊断场景是否有效。

**写作期**
5. **章节续写** — 依据大纲与场景卡片，产出 `正文/<部>/<章节>.md`；每章写前先读设定、人物状态与上一章。

**修订期**
6. **连贯性检查** — 通读正文，把矛盾、断线记入 `修订/连贯性问题.md`。
7. **结构修订** — 处理情节 / 节奏 / 结构问题，产出 `修订/结构修订清单.md`。
8. **文字润色** — 句层优化，记录到 `修订/章节修订记录/`。

**循环**
9. **创作复盘** — 周期性回顾进度与手感，产出 `创作管理/创作复盘.md`。

> 不是每次都走完 9 步。日常写作主要是 5（续写）+ 6/7/8（修订）；构思期只走 1–4。

## 四、文件与命名约定

- 严格遵循 `项目说明/命名规范.md`。核心规则：
  - 章节正文：`正文/<部>/第NNN章-<标题>.md`（章号三位数）。
  - 人物档案：`人物/主要人物/<姓名>.md`、`人物/次要人物/<姓名>.md`。
  - 修订记录：`修订/章节修订记录/<章节slug>.md`。
  - 文档内链统一用工作区相对路径（见命名规范）。
- 正文用 Markdown；图片 / 地图等二进制素材放 `素材与研究/创作素材/图片与地图/`。
- **版本意识**：改写不直接覆盖旧稿前，先按 `项目说明/版本规则.md` 处理（重要改动用 git 或副本留痕）。

## 五、Agent 协作原则

- **一致性优先**：任何新增内容都必须先过 `小说设定/故事事实与规则.md` 与 `人物/当前人物状态.md`，不违背既定设定。
- **谁的输入谁负责**：续写前先确认大纲、场景、上一章就绪。
- **只动自己职责内的文件**：续写不擅自改大纲；润色不改情节。
- **留下可追溯的痕迹**：在 `创作管理/当前写作.md` 与修订记录中记录做了什么、何时。
- **不确定就问**：涉及剧情重大转向、人物死亡、结局等，必须先与用户确认。
- **中文输出**：除专有名词外，一律简体中文。
