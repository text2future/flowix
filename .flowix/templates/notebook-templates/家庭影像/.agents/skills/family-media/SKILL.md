## 推进本主题

本主题流程：资料汇集 → 分类去重 → 修复标注 → 作品制作 → 备份分享。

1. **资料汇集**：按设备和家庭成员汇集资料，确认隐私与分享范围。
2. **分类去重**：按事件和时间归类，去重时保留原始文件信息。
3. **修复标注**：修复必要问题并确认人物、日期，不确定项明确标注。
4. **作品制作**：按用途选片和编排，核对图注与事件对应。
5. **备份分享**：确认备份位置与可读取性，按授权范围分享成品。

- 任务入口：`进度视图.csv`。按事项ID查找记录，展示给用户时使用任务名称。
- 决策与依据：`待整理/计划表.csv`、`待整理/资料/资料清单.csv`。
- 新任务：复制 `公共/影像批次单.md`，在 `影像/` 下用可读的任务名称建目录；场次、批次等重复任务加日期。
- 填写案例与真实任务时沿用空白模板的标题和字段，不另造一套简化结构。字段不适用写明原因；资料缺失时说明缺口及影响。过程写已发生的动作，产物保存到任务目录并登记实际路径。
- 结果写入 `数据/影像索引.csv`，沿用同一事项ID。检查字段单位、时间范围和对象粒度；单次任务不填项目累计数。缺失值不得用0代替。
- 本主题完成条件：人物隐私、分享范围和备份完整性确认。先逐项核对模板中的审核字段，再更新状态；缺少影响验收的证据时保持待确认。

## 本库中的教学记录

`影像/2019年春节影像批次/任务记录.md` 与 `影像/2019年春节影像批次/春节影像编目.md` 展示一次任务的记录及产物。其中人物和数据为模拟；未经用户要求，不把模拟数据当作真实事实或继续虚构实际结果。外部发布、支付和联系按用户授权执行。

数据记录先确认一行代表什么对象、哪段时间与什么单位。原始记录、分类合计和项目汇总分别维护；验收表的期望结果必须与实际结果逐项对应，不能只填写“通过”。
