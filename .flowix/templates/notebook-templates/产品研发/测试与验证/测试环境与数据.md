# 测试环境与数据

> 规定测试跑在哪、用什么数据。**核心红线：禁止使用生产数据。**

## 一、环境清单

| 环境 | 用途 | 数据 | 访问 |
| --- | --- | --- | --- |
| local | 开发自测 | 合成 | 开发者本机 |
| CI | 自动化测试 | 合成（每次重建） | 流水线 |
| staging | 发布前验证 | 脱敏 / 合成 | 团队 |
| prod | 生产 | 真实 | 严格限制 |

## 二、数据来源规则（红线）

| 环境 | 允许 | 禁止 |
| --- | --- | --- |
| local / CI | 合成 / 自行创建 | **生产数据** |
| staging | 脱敏导出 / 合成 | **未脱敏的生产数据** |

> **禁止**把生产数据复制到任何非生产环境——即使是"我自己复制的"也违规。

## 三、合成数据

生成方式：`pnpm db:seed`（基础种子）+ `pnpm seed:fixtures`（合成数据集）。

必须覆盖：正常内容、**中文内容**、边界（空 / 超大 / 超长）、超限文件、大小写同名、规模数据（性能测试用）。

> 必须**可一键重建**，用固定种子保证可重复，**禁止**依赖手工准备。

## 四、脱敏规则（仅在必要时）

| 字段 | 脱敏方式 |
| --- | --- |
| 姓名 / 邮箱 | 替换为假值 |
| 手机号 | 掩码 / 假值 |
| 业务标识 | 替换为通用值 |
| 凭据 / 密钥 | 完全不导出 |

流程：申请 → 安全评审 → 隔离环境脱敏 → 使用 → 到期删除。

## 五、环境隔离

| 项 | 要求 |
| --- | --- |
| 数据库 | 各环境独立实例，**禁止**跨环境连接 |
| 密钥 | 各环境独立，**禁止**共用生产密钥 |
| 第三方服务 | staging 用沙箱 / mock |
| 邮件 / 支付 | **禁止**发真实邮件、**禁止**真实扣款 |

## 六、测试账号

| 环境 | 密码存放 |
| --- | --- |
| local | `.env`（本地） |
| staging | 密钥管理（见 `发布与运行/配置与密钥管理.md`） |
| CI | CI secrets |

> 测试账号密码**禁止**写进代码 / 文档。

## 七、数据重置

| 环境 | 重置方式 |
| --- | --- |
| local | `pnpm db:reset` |
| CI | 每个 job 前重建 |
| staging | 定期 + 发布前 |
