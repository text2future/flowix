# 端到端测试

> 跑在**完整应用**上的真实用户路径验证。**只覆盖关键路径**——E2E 慢且脆，**禁止**把逻辑验证塞进来。

## 一、覆盖范围

| # | 路径 | 标签 | 状态 |
| --- | --- | --- | --- |
| E2E-01 | <登录 → 首页> | @critical | |
| E2E-02 | <核心主流程> | @critical | |

> 数量控制在个位数。每新增一条，先自问"这条非 E2E 验证不了吗"。

## 二、执行

```bash
pnpm test:e2e                       # 无头
pnpm test:e2e -- --headed           # 可见窗口，便于排查
pnpm test:e2e -- --grep "<场景>"
pnpm test:e2e -- --repeat-each=3    # 检测 flaky
```

## 三、选择器约定

| 优先级 | 方式 | 示例 |
| --- | --- | --- |
| 1 | `data-testid` | `[data-testid="submit"]` |
| 2 | 角色 + 名称 | `getByRole('button', { name: '...' })` |
| 3 | 文本 | `getByText('...')` |
| ❌ | CSS class / 层级 | `.btn-primary > span` |

> 可交互元素**必须**有 `data-testid` 或语义化 role。

## 四、测试数据

| 项 | 要求 |
| --- | --- |
| 来源 | `tests/fixtures/`（合成数据） |
| 准备 / 清理 | 用例自行复制到临时位置、结束删除 |
| **禁止** | 使用真实用户目录 / 生产数据 |

## 五、稳定性要求

| 要求 | 做法 |
| --- | --- |
| 不依赖时间 | 用条件等待，**禁止** `waitForTimeout` |
| 不依赖顺序 | 每个用例独立准备数据 |
| 不依赖动画 | 禁用动画 / 等待稳定 |
| 不依赖网络时序 | 拦截并 mock 外部请求 |
| 失败可诊断 | 自动截图 + trace |

> flaky 用例**必须修**（用 `--repeat-each=3` 检测），**禁止**重跑直到绿。

## 六、CI 集成

| 阶段 | 执行 |
| --- | --- |
| PR | 关键子集（`@critical`） |
| 合并主干 | 全量 |
| 发布前 | 全量 + 跨平台冒烟 |

## 七、跨平台

| 平台 | CI | 发布前手工 |
| --- | --- | --- |
| Windows | 必跑 | 是 |
| macOS | 必跑 | 是 |
| Linux | 可选（桌面环境依赖） | 冒烟 |

## 八、失败排查

| 现象 | 常见原因 | 处理 |
| --- | --- | --- |
| 元素找不到 | 选择器失效 / 未等待 | 修选择器 / 加条件等待 |
| 偶发失败 | 竞态 / 动画 / 网络 | 条件等待 / mock 网络 |
| 本地过 CI 不过 | 环境差异 | 查 CI 日志，统一环境 |
| 超时 | 数据过大 | 缩小测试数据 |
