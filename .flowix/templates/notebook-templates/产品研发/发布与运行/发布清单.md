# 发布清单

> **发布前逐项确认。** 任一项不满足即**不可发布**；需突破时按 `.agents/rules/开发原则.md` 的豁免流程走。
> 单次发布的详细计划写在各 `变更/CHG-xxx/发布计划.md`。

## 一、代码与验证

- [ ] 变更已完成 `代码审查与风险检查`，无未解决的高风险项
- [ ] `验证计划.md` 中的**关键验证项**全部执行且通过（**未执行 ≠ 通过**）
- [ ] 冒烟测试全过（`测试与验证/冒烟测试.md`）
- [ ] 回归测试**关键用例**全过
- [ ] 有覆盖本次改动的自动化测试（缺陷修复必须有"修复前为红"的用例）

## 二、契约与文档

- [ ] 契约变更已登记（`模块与契约/`）
- [ ] 兼容性已判定；破坏性变更已有过渡方案 + ADR
- [ ] `.agents/context/` 已同步（代码地图 / 模块边界 / 契约索引）
- [ ] `开发者入口/` 相关说明已更新（命令 / 流程若有变化）

## 三、数据与迁移

- [ ] 涉及迁移的已提供 **up 与 down** 并实测
- [ ] 破坏性迁移**已有可用备份**
- [ ] 数据回填方案幂等、分批、可中断

## 四、配置与开关

- [ ] 新增配置已登记并有安全默认值
- [ ] 无密钥入库
- [ ] 涉及的 Flag 已登记，默认值符合预期
- [ ] 过期 Flag 已清理

## 五、回滚（**必填**）

- [ ] 回滚触发条件已明确（量化）
- [ ] 回滚步骤已写明并**实测过**
- [ ] 数据回滚方案已明确（含"本次无需数据回滚"的判断依据）
- [ ] 回滚负责人已指定

## 六、发布后

- [ ] 观察窗口与观察指标已定
- [ ] 告警已覆盖新路径（且对应 Runbook 已存在）
- [ ] 发布记录已建（`发布与运行/发布记录/`）
