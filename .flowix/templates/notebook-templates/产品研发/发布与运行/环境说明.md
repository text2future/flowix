# 环境说明

> 环境清单与差异。**任何"只在某个环境才会出现"的问题，先查这张表。**

## 一、环境清单

| 环境 | 用途 | 数据 | 访问控制 | 谁可以发布 |
| --- | --- | --- | --- | --- |
| local | 开发自测 | 合成 | 本机 | 开发者 |
| staging | 发布前验证 | 脱敏 / 合成 | 团队 | <角色> |
| prod | 生产 | 真实 | 严格限制 | <角色> |

## 二、环境差异

| 项 | local | staging | prod |
| --- | --- | --- | --- |
| 数据库 | 本地 | 独立实例 | 独立实例 |
| 第三方服务 | mock | 沙箱 | 真实 |
| 日志级别 | debug | info | info / warn |
| 告警 | 无 | 有 | 有 |
| 数据规模 | 小 | 中 | 真实 |

> **红线**：环境之间**不共用**数据库与密钥；**禁止**把生产数据复制到非生产环境。

## 三、配置来源

| 环境 | 配置来源 |
| --- | --- |
| local | `.env`（不入库） |
| staging / prod | 密钥管理（见 `配置与密钥管理.md`） |

## 四、常见"环境相关"问题

| 现象 | 常见原因 |
| --- | --- |
| 本地过、CI 不过 | 环境变量 / 版本 / 时区差异 |
| staging 正常、prod 异常 | 数据规模 / 真实第三方 / 配置差异 |
| 只在某平台出现 | 见 `模块与契约/桌面端与本地能力/跨平台差异.md` |

## 五、维护规则

- 新增环境 → 更新本表 + 明确发布权限。
- 环境差异导致的缺陷 → 复盘时**必须**检查是哪一类差异（见 `事件与问题/问题模式与防回归.md`）。
