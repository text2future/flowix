# 配置与密钥管理

> **凭据是最敏感资产。** 本文件规定放哪、怎么取、怎么轮换。

## 一、配置分级

| 级别 | 内容 | 存放 | 可否入库 |
| --- | --- | --- | --- |
| 公开 | 非敏感默认值 | 代码 / 配置文件 | ✅ |
| 环境相关 | 地址、开关、阈值 | 环境变量 | ⚠️ 给默认值，真值在外 |
| 密钥 | API Key、数据库口令、签名私钥 | 密钥管理 | ❌ **绝对禁止** |

> **红线**：密钥**不得**出现在代码、文档、日志、错误信息、提交历史中。一旦提交过，**视为已泄露**，必须轮换。

## 三、密钥操作

| 操作 | 流程 |
| --- | --- |
| 申请 | <流程 + 审批> |
| 下发 | 走密钥管理，**不**通过聊天工具传明文 |
| 轮换 | <周期 + 触发条件（人员变动 / 疑似泄露）> |
| 撤销 | 立即，并确认旧凭据已失效 |
| 本地开发 | 用**独立的开发凭据**，权限最小 |

## 四、校验

- [ ] 启动时校验必填配置，缺失**必须**明确报错（而非静默用错值）
- [ ] 密钥不落日志（含异常堆栈）
- [ ] 配置变更走评审；密钥变更走审批
- [ ] 提交前有密钥扫描

## 五、维护规则

- 新增 / 删除配置 → 同步本表 + 各环境实际配置。
- 密钥轮换 → 记录到发布记录。
- 疑似泄露 → **立即**按安全事件处理（见 `.agents/rules/安全与隐私规则.md`）。
