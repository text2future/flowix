## 二、填写范例

### F-06 大目录导入内存暴涨

| 项 | 内容 |
| --- | --- |
| 现象 | 导入大目录时内存持续上升，界面卡顿甚至崩溃 |
| 常见原因 | 一次性读取全部条目；未分批；未设上限 |
| 快速判定 | 观察导入过程中内存曲线是否单调上升 |
| 止血 | 中断导入；限制单次规模 |
| 根治 | 分批处理 + 资源上限（对应变更 CHG-2026-001） |
