## 三、脆弱点

| 风险 | 说明 | 缓解 |
| --- | --- | --- |
| 服务不可用 | 依赖方故障 | 降级 / 缓存 |
| 配额限制 | 超限被拒 | 限流 + 监控 |
| 接口变更 | 对方升级 | 锁定版本 / 契约测试 |
| 停止维护 | 库不再更新 | 记入 `架构决策/依赖升级计划.md` |

## 五、维护规则

- 新增外部依赖 → 登记本表 + 评估许可证与安全（见 `.agents/rules/安全与隐私规则.md`）。
- 依赖方接口变更 → 走兼容性判定。
- 定期复核依赖健康度（是否停更、是否有漏洞）。
