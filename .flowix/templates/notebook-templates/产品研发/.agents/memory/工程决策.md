# 工程决策

> **性质**：长期记忆。记录**日常技术取舍**——"为什么当初这么定"。
> 与 ADR 的分工：有完整备选对比、经正式评审的**重大决策写 ADR**（`架构决策/ADR/`）；其余中等以下的选择写这里，不重复。

## 一、使用方式

- 每次做出"不那么显然"的选择 → 追加一条。
- 只写**结论 + 理由 + 代价**，不写过程与流水账。
- 决策失效 → 标注"已失效（被 GD-NN 取代）"，**不删除**（历史有价值）。

## 二、条目格式

### GD-NN · <决策标题>

| 项 | 内容 |
| --- | --- |
| 日期 | YYYY-MM-DD |
| 背景 | <为什么必须做选择> |
| 选择 | <选了什么> |
| 理由 | <核心判断依据>（禁止写"因为更好"） |
| 代价 | <放弃了什么 / 留下什么限制>（**必填**） |
| 关联 | ADR-NN / CHG-NNN / D-NN / PT-NN |
