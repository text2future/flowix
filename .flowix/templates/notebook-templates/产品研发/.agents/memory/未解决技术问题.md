# 未解决技术问题

> **性质**：长期记忆。记录**已知但尚未解决**的问题——不遗忘、不重复踩、有据可查。
>
> 与相邻概念的区别（**不要混用**）：
> - **技术债**（`架构决策/技术债务.md`）= 主动的妥协，已有方案与偿还计划；
> - **已知限制**（`事件与问题/已知限制.md`）= 已接受的边界，不打算改；
> - **日常技术取舍**（`.agents/memory/工程决策.md`）= 已经做出的决定；
> - 本文件 = **还没找到解法**或暂无优先级处理。

## 一、条目格式

### U-NN · <问题标题>

| 项 | 内容 |
| --- | --- |
| 发现日期 | YYYY-MM-DD |
| 现象 | <...> |
| 已探索 | <试过什么、为什么行不通>（**必填**，否则等于没查） |
| 当前绕过 | <现在怎么应对> |
| 影响 | <用户 / 系统能感知到什么> |
| 优先级 | 高 / 中 / 低 |
| 关联 | CHG-NNN / D-NN / F-NN |
