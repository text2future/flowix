# 经验与陷阱

> **性质**：长期记忆。记录**踩过的坑与反直觉的点**，每条都要能"下次避免再犯"。
> 写回来源：`代码与规格收敛`、`缺陷定位与修复`、`线上事件诊断与复盘`。

## 一、使用方式

- 一条一个坑，写清 **触发场景 → 后果 → 正确做法 → 预防措施**。
- 只记**可复用**的，不记一次性问题。
- 已通过代码 / CI 根治的 → 标"已加固"，**保留不删**（说明曾经踩过）。
- 同类坑重复出现 → 提建议升级为规则（**只建议，不擅改 `.agents/rules/`**）。

## 二、条目格式

### PT-NN · <陷阱标题>

| --- | --- |
| 场景 | <什么情况下会踩到> |

| 预防 | <如何在 CI / 评审 / 规则上拦住> |
| 状态 | 待观察 / 已加固 |
