# 开发环境准备

> 一次性配置。**目标：新人半天内能跑起来。** 若做不到，说明本文件或工程本身需要修。

## 一、前置要求

| 项 | 要求 | 校验命令 |
| --- | --- | --- |
| 运行时 | <版本> | `<cmd> --version` |
| 包管理器 | <名称> | `<cmd> --version` |
| 操作系统 | <支持范围> | — |
| 其他 | <原生工具链等> | `<cmd>` |

## 二、步骤

```bash
git clone <repo>
cd <repo>
<安装依赖命令>
<复制环境变量示例>
<初始化数据库 / 本地数据>
<启动命令>
```

| # | 步骤 | 预期 |
| --- | --- | --- |
| 1 | 安装依赖 | 无报错，**含原生模块重建** |
| 2 | 配置环境变量 | 必填项齐全（见 `.agents/context/技术栈与本地环境.md`） |
| 3 | 初始化数据 | 生成合成数据，**禁止**用生产数据 |
| 4 | 启动 | 能打开并能走通一条主流程 |

## 三、验证装好了

- [ ] 类型检查 / Lint 通过
- [ ] 单元测试通过
- [ ] 应用能启动
- [ ] 能完成一次最小主流程

## 四、常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 安装后启动崩溃 | 原生模块 ABI 不匹配 | 重建原生模块 |
| 找不到命令 | 依赖未装全 / PATH | 重装依赖 |
| 端口被占用 | 有旧进程 | 结束进程或改端口 |

> 环境类问题**首次遇到就要补进本表**——下一个人一定会遇到。

## 五、维护规则

- 依赖或命令变化 → 立即更新本文件（**这是最容易过期的一类文档**）。
- 若某步骤无法复现成功 → 视为工程问题，修脚本而不是加"注意事项"。
