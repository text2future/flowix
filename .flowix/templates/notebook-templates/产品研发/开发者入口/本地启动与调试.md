# 本地启动与调试

> 怎么跑起来、怎么看日志、怎么断点。

## 一、启动方式

| 场景 | 命令 | 说明 |
| --- | --- | --- |
| 全部起 | `<cmd>` | 常规开发 |
| 只起后端 | `<cmd>` | 前端用已有构建 |
| 只起前端 | `<cmd>` | 调试 UI |
| 生产模式 | `<cmd>` | 复现构建后问题 |

## 二、调试手段

| 目标 | 方式 |
| --- | --- |
| 断点 | <编辑器附加到哪个进程> |
| 日志 | <日志位置 / 输出方式> |
| 网络请求 | <抓包 / 拦截工具> |
| 本地数据 | <数据文件 / 库位置> |
| 前端状态 | <调试工具> |

## 三、常用开关

| 变量 | 作用 |
| --- | --- |
| `<DEBUG_*>` | <开启详细日志 / 不过滤> |
| `<MOCK_*>` | <用 mock 替代外部依赖> |

> 调试开关**只能**在非生产环境生效，**禁止**用调试开关绕过安全校验。

## 四、日志与追踪

| 项 | 做法 |
| --- | --- |
| 追踪 ID | 每个请求 / 任务带 ID，便于串联 |
| 复现线上问题 | 用同参数 + 同数据规模本地复现 |
| 无法本地复现 | 走 staging，并补充可观测信息 |

## 五、维护规则

- 命令变化 → 同步本文件与 `常用命令.md`。
- 调试技巧（非显而易见的那种） → 记入 `.agents/memory/经验与陷阱.md`。
