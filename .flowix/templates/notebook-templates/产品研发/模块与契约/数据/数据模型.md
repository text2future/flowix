# 数据模型

> 存储结构的**唯一权威描述**。代码里的实体定义必须与本文件一致。

## 一、实体清单


| 实体         | 表名        | 说明          | 关键字段          |
| ---------- | --------- | ----------- | ------------- |
| &lt;实体&gt; | `<table>` | &lt;一句话&gt; | id、created_at |


## 二、字段约定


| 项   | 规则                                        |
| --- | ----------------------------------------- |
| 主键  | 统一 `<id 形式>`（自增 / UUID），**全库一致**          |
| 时间  | 统一 UTC 存储，字段名 `created_at` / `updated_at` |
| 软删除 | &lt;是否使用；若用，查询必须带过滤条件&gt;                 |
| 枚举  | 存**稳定字符串**而非序号，避免插入新值打乱语义                 |
| 空值  | 明确"为空"的含义（未知 / 不适用 / 未设置）                 |
| 命名  | 表用复数、字段用 snake_case（或统一为项目约定）             |


## 三、关系

```
<实体 A> 1 ──── n <实体 B>
```


| 关系    | 基数  | 删除策略                     |
| ----- | --- | ------------------------ |
| A → B | 1:n | 级联 / 置空 / 禁止（**必须显式声明**） |


## 四、填写范例


| 实体  | 表名           | 说明         | 关键字段               |
| --- | ------------ | ---------- | ------------------ |
| 工作区 | `workspaces` | 一个被纳管的本地目录 | id、path、created_at |


## 五、维护规则

- 改结构 → **必须**同时提供迁移（见 `模块与契约/数据/Schema迁移.md`）。
- 本文件与代码不一致 = **视为缺陷**。
- **禁止**在无迁移的情况下改字段语义。
