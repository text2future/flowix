## 二、事件契约要求

| 项 | 要求 |
| --- | --- |
| 命名 | `<主体>.<动作>`，过去式，稳定后**不改名** |
| 版本 | 载荷变更走版本字段，**禁止**直接改同名事件的语义 |
| 幂等 | 消费方**必须**按事件 ID 去重 |
| 顺序 | 声明是否需要有序；需要则给出分区键 |
| 失败 | 必须有重试与死信出口，**禁止**静默丢弃 |

## 五、维护规则

- 新增 / 修改事件 → 更新本表 + `.agents/context/API与事件契约.md` 索引。
- 删除事件 → 确认无消费方后再删，并记入 `历史归档/已替代规范/`。
