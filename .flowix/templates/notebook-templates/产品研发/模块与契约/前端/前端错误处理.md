# 前端错误处理

> 规定错误**在哪一层被捕获与展示**，以及错误码到用户文案的映射。

## 一、错误分层

| 层 | 捕获什么 | 展示方式 |
| --- | --- | --- |
| 页面级 | 渲染异常 | 错误页 + 重试 |
| 请求层 | 接口失败（网络 / 业务码） | toast / 内联提示 |
| 表单层 | 字段校验 | 字段下方提示 |
| 全局 | 未捕获异常 | 兜底页 + 上报 |

> **原则**：错误**必须**被某一层接住并可见，**禁止**静默吞掉。

## 二、请求错误的表现约定

| 错误类型 | 表现 | 是否重试 |
| --- | --- | --- |
| 网络失败 | 明确提示"网络异常" | 可重试 |
| 未登录 / 无权限 | 跳登录或提示无权限 | 否 |
| 业务错误 | 用错误码对应文案 | 视情况 |
| 未知错误 | 通用文案 + 提供追踪 ID | 可重试 |

> 文案与错误码的映射见 `模块与契约/后端/错误码与异常约定.md`。**禁止**把原始报错直接抛给用户。

## 三、填写范例

| 错误码 | 用户可见文案 | 展示位置 |
| --- | --- | --- |
| `<CODE-A>` | "文件无法读取，请检查权限" | 内联 |

## 四、维护规则

- 新增错误码 → 同步本节 + `模块与契约/后端/错误码与异常约定.md` + `模块与契约/前端/页面与路由.md`（若涉及跳转）。
- 每个错误提示**必须**回答：发生了什么 + 用户能做什么。
