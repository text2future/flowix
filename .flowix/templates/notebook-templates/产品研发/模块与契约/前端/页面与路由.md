# 页面与路由

> 前端页面清单与路由约定。**新增页面必须先在此登记**，再写代码。

## 一、路由表

| 路径 | 页面 | 是否需要登录 | 核心状态 | 备注 |
| --- | --- | --- | --- | --- |
| `/` | <首页> | 否 | — | |
| `/...` | <页面名> | 是 | loading / empty / error | |

> 每页必须声明**三种状态**（加载 / 空 / 错误），只写"正常态"不算完成。

## 二、路由约定

| 约定 | 规则 |
| --- | --- |
| 命名 | <小写 + 连字符 / 层级用嵌套路由> |
| 参数 | <路径参数 vs 查询参数的选择标准> |
| 懒加载 | <哪些页面按需加载> |
| 权限 | <未登录跳哪里；无权限时的表现> |
| 未知路径 | 必须落到 404 页，**禁止**白屏 |

## 三、填写范例

| 路径 | 页面 | 是否需要登录 | 核心状态 | 备注 |
| --- | --- | --- | --- | --- |
| `/workspaces/:id` | 工作区详情 | 是 | loading / empty / error | 参数非法时跳 404 |

## 四、维护规则

- 新增 / 删除页面 → 更新本表 + 检查 `前端错误处理.md` 是否需要补错误页。
- 路由结构变化 → 评估是否影响深链接与外部文档。
