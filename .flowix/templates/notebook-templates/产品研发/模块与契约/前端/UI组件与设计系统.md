# UI 组件与设计系统

> 组件的来源与使用规则。目标：**页面里不出现"一次性样式"**。

## 一、组件来源

| 来源 | 说明 | 可否改 |
| --- | --- | --- |
| 设计系统基础件 | 按钮 / 输入 / 弹窗等 | 通过令牌调，不改结构 |
| 业务组件 | 多页面复用的组合件 | 可，但需评审 |
| 页面私有 | 只在一个页面用 | 可 |

> **规则**：出现第二次复用 → 上提为业务组件；只有一次 → 留在页面内，**不要提前抽象**。

## 二、设计令牌

| 类别 | 变量 | 约束 |
| --- | --- | --- |
| 颜色 | `--color-*` | **禁止**在组件里写死 HEX |
| 间距 | `--space-*` | 使用固定阶梯，不随意取值 |
| 字号 | `--font-*` | 同上 |
| 圆角 / 阴影 | `--radius-*` / `--shadow-*` | 同上 |

## 三、填写范例

| 组件 | 来源 | 使用位置 |
| --- | --- | --- |
| `<Button>` | 设计系统 | 全局 |
| `<ImportDialog>` | 业务组件 | 工作区导入、设置页复用 |

## 四、维护规则

- 新增基础件 → 同步设计系统（并通知设计）。
- 主题（明暗）适配**必须**用令牌，**禁止**用条件分支写两套颜色。
- 组件废弃 → 标注替代者，不直接删（避免引用断裂）。
