# Webhook 与外部集成

> 把系统事件推给外部方的契约。**外部方不受我们控制，容错要求更高。**

## 一、对外订阅

| 事件 | 触发 | 投递方式 | 重试 | 载荷版本 |
| --- | --- | --- | --- | --- |
| `<event.name>` | <何时> | HTTP POST | 指数退避 + 上限 | vN |

## 二、投递保证

| 项 | 约定 |
| --- | --- |
| 至少一次 | 消费方**必须**按事件 ID 幂等 |
| 签名 | 请求带签名，消费方**必须**验签 |
| 超时 | 明确超时；超时即视为失败并重试 |
| 重试 | 上限后进死信，可**人工重放** |
| 顺序 | **不保证**；需要顺序时在载荷里带序号 |
| 停止投递 | 连续失败达阈值 → 自动停并通知 |

## 三、填写范例

| 事件 | 触发 | 投递方式 | 重试 | 载荷版本 |
| --- | --- | --- | --- | --- |
| `<workspace.imported>` | 导入完成 | HTTP POST | 5 次退避 | v1 |

## 四、维护规则

- 新增外部集成 → 登记本表 + 在 `发布与运行/配置与密钥管理.md` 登记所需凭据。
- 载荷变更 → 走版本，**不覆盖**已发布的版本。
- 集成失败排查路径 → 记入 `.agents/memory/常见排查路径.md`。
