# 认证与授权

> 规定**谁以什么身份调用**，以及**能做什么**。

## 一、认证方式

| 场景 | 方式 | 有效期 | 存储 |
| --- | --- | --- | --- |
| 用户会话 | <token / cookie> | | 客户端安全存储 |
| 服务间 | <密钥 / 签名> | | 密钥管理 |
| 外部集成 | <API Key / OAuth> | | 见 `模块与契约/API/Webhook与外部集成.md` |

> 凭据**禁止**写进代码、日志、错误信息。

## 二、授权模型

| 资源 | 动作 | 需要什么权限 | 判定位置 |
| --- | --- | --- | --- |
| <资源> | 读 / 写 / 删 | <角色 / 属主> | 服务端 |

> **红线**：授权判定**只在服务端**。前端隐藏按钮只是体验，**不是**安全措施。

## 三、会话与失效

| 项 | 约定 |
| --- | --- |
| 过期 | <时长 + 续期方式> |
| 主动失效 | 登出 / 改密 / 权限变更时**必须**失效 |
| 并发 | <是否允许同账号多端> |

## 四、填写范例

| 资源 | 动作 | 需要什么权限 | 判定位置 |
| --- | --- | --- | --- |
| 工作区 | 读 | 属主或协作者 | 服务端 |

## 五、维护规则

- 新增受保护资源 → 登记第二节 + 补 `模块与契约/API/API目录.md` 的认证列。
- 权限模型变化 → **必须**写 ADR。
