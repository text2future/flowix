# 文件系统权限

> **本地能力是最容易越界的部分。** 本文件规定：能碰什么、怎么碰、碰了怎么记录。

## 一、权限模型

| 范围 | 可做 | 禁止 |
| --- | --- | --- |
| 用户显式选定的目录 | 读取 / 建立索引 | **写入 / 修改 / 删除用户文件** |
| 应用自身数据目录 | 读写 | 越界访问 |
| 系统关键目录 | **不可访问** | 任何操作 |
| 符号链接 / 外部挂载 | 需显式策略 | 无提示跟随 |

> **红线**：产品承诺"只读"，就**不得**有任何写用户文件路径的代码分支。

## 二、访问约定

| 项 | 约定 |
| --- | --- |
| 授权获取 | 通过系统选择器，**不猜测**路径 |
| 路径校验 | 解析真实路径后再判定范围（防路径穿越） |
| 失效处理 | 权限被收回 / 目录被移走 → 标记不可访问，**不崩** |
| 大目录 | 必须可中断、可恢复，不能阻塞 |
| 敏感目录 | 有排除清单（见 `.agents/rules/安全与隐私规则.md`） |

## 三、填写范例

| 场景 | 行为 |
| --- | --- |
| 用户选择项目目录 | 只读扫描，建立索引 |

## 四、维护规则

- 新增任何文件系统调用 → **必须**走 `代码审查与风险检查`，并复核本节。
- 权限相关缺陷 → 定级不低于 P1。
- 相关经验记入 `.agents/memory/经验与陷阱.md`。
