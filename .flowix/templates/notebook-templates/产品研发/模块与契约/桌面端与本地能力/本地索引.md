# 本地索引

> 本地索引的结构与更新策略。它是"检索能力"的地基。

## 一、索引结构

| 项 | 内容 |
| --- | --- |
| 存储 | `<本地库 / 文件格式>` |
| 内容 | <索引哪些字段；是否含正文> |
| 分词 | <方案；中文需专门处理> |
| 排序 | <排序依据> |
| 与源文件关系 | 索引**可重建**，源文件始终是权威 |

> **原则**：索引**永远**可以从源重建。**禁止**让索引成为不可再生的唯一数据。

## 二、更新策略

| 事件 | 触发方式 | 延迟预期 |
| --- | --- | --- |
| 新增文件 | 监听 / 定时扫描 | <秒 / 分钟> |
| 修改 | 同上 | 同上 |
| 删除 | 同上，且**必须**清理索引 | 同上 |
| 全量重建 | 手动 / 索引损坏 | 可中断 |

| 项 | 约定 |
| --- | --- |
| 增量 | 优先增量；全量仅作为兜底 |
| 并发 | 与读写并存时的行为（**必须**明确） |
| 资源上限 | 有内存 / CPU 上限，超限降速而非崩 |
| 中断恢复 | 中途退出后**必须**能续 |

## 三、填写范例

| 项 | 内容 |

## 四、维护规则

- 索引结构变更 → **必须**提供重建方案与耗时评估。
- 索引与源不一致 → 视为缺陷，按 `缺陷定位与修复` 处理。
- 性能相关结论 → 记入 `发布与运行/容量与性能.md`。
