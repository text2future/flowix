## 推进本主题

本主题流程：场景与品类 → 供应商筛选 → 样品验收 → 上架陈列 → 销售复盘。

1. **场景与品类**：从使用空间出发选择品类，明确尺寸与场景需求。
2. **供应商筛选**：比较规格、采购条件、交付和售后限制。
3. **样品验收**：核对到货、抽装或试用，记录缺件和安装说明问题。
4. **上架陈列**：补齐尺寸和使用说明，按库存安排展示与上架。
5. **销售复盘**：结合销量、咨询和退货原因调整选品及说明。

- 任务入口：`进度视图.csv`。按事项ID查找记录，展示给用户时使用任务名称。
- 决策与依据：`商品/计划表.csv`、`商品/资料/资料清单.csv`。
- 新任务：复制 `公共/商品采购单.md`，在 `商品/` 下用可读的任务名称建目录；场次、批次等重复任务加日期。
- 填写案例与真实任务时沿用空白模板的标题和字段，不另造一套简化结构。字段不适用写明原因；资料缺失时说明缺口及影响。过程写已发生的动作，产物保存到任务目录并登记实际路径。
- 结果写入 `数据/采购与库存.csv`，沿用同一事项ID。检查字段单位、时间范围和对象粒度；单次任务不填项目累计数。缺失值不得用0代替。
- 本主题完成条件：样品质量、规格和交付方式确认。先逐项核对模板中的审核字段，再更新状态；缺少影响验收的证据时保持待确认。

## 本库中的教学记录

`商品/窄边置物架首批入库/任务记录.md` 与 `商品/窄边置物架首批入库/窄边置物架入库单.md` 展示一次任务的记录及产物。其中人物和数据为模拟；未经用户要求，不把模拟数据当作真实事实或继续虚构实际结果。外部发布、支付和联系按用户授权执行。

数据记录先确认一行代表什么对象、哪段时间与什么单位。原始记录、分类合计和项目汇总分别维护；验收表的期望结果必须与实际结果逐项对应，不能只填写“通过”。
