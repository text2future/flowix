## 推进本主题

本主题流程：系统盘点 → 字段映射 → 试迁校验 → 正式切换 → 运行观察。

1. **系统盘点**：清点系统、对象、依赖和不可中断服务。
2. **字段映射**：确认源目标字段、转换规则与冲突处置。
3. **试迁校验**：试迁后核对数量和字段，修复差异并演练回滚。
4. **正式切换**：满足验收与回退条件后执行切换，记录关键节点。
5. **运行观察**：核对增量数据和业务操作，处理遗留问题再结束观察。

- 任务入口：`进度视图.csv`。按事项ID查找记录，展示给用户时使用任务名称。
- 决策与依据：`映射与方案/计划表.csv`、`映射与方案/资料/资料清单.csv`。
- 新任务：复制 `公共/迁移批次单.md`，在 `迁移/` 下用可读的任务名称建目录；场次、批次等重复任务加日期。
- 填写案例与真实任务时沿用空白模板的标题和字段，不另造一套简化结构。字段不适用写明原因；资料缺失时说明缺口及影响。过程写已发生的动作，产物保存到任务目录并登记实际路径。
- 结果写入 `数据/迁移校验.csv`，沿用同一事项ID。检查字段单位、时间范围和对象粒度；单次任务不填项目累计数。缺失值不得用0代替。
- 本主题完成条件：备份、数量核对和可执行回滚验证。先逐项核对模板中的审核字段，再更新状态；缺少影响验收的证据时保持待确认。

## 本库中的教学记录

`迁移/2026-10-28 第一批客户资料迁移/任务记录.md` 与 `迁移/2026-10-28 第一批客户资料迁移/首批迁移核对单.md` 展示一次任务的记录及产物。其中人物和数据为模拟；未经用户要求，不把模拟数据当作真实事实或继续虚构实际结果。外部发布、支付和联系按用户授权执行。

数据记录先确认一行代表什么对象、哪段时间与什么单位。原始记录、分类合计和项目汇总分别维护；验收表的期望结果必须与实际结果逐项对应，不能只填写“通过”。
