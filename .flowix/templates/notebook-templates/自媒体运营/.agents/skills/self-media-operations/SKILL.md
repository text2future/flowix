## 推进本主题

本主题流程：定位 → 选题 → 创作 → 发布 → 复盘。

1. **定位**：确定受众、栏目、内容承诺和验证周期。
2. **选题**：从读者问题建立选题，确认资料与计划发布日期。
3. **创作**：完成正文或脚本，整理素材并逐项处理审核意见。
4. **发布**：核对定稿与素材后发布，记录时间、版本和平台回执。
5. **复盘**：按固定窗口登记单篇数据与反馈，再决定下一条内容。

- 任务入口：`内容视图.csv`。按事项ID查找记录，展示给用户时使用任务名称。
- 决策与依据：`选题/内容日历.csv`、`选题/资料/资料清单.csv`。
- 新任务：复制 `公共/单条内容卡.md`，在 `创作/2026-10/` 下用可读的任务名称建目录；场次、批次等重复任务加日期。
- 填写案例与真实任务时沿用空白模板的标题和字段，不另造一套简化结构。字段不适用写明原因；资料缺失时说明缺口及影响。过程写已发生的动作，产物保存到任务目录并登记实际路径。
- 结果写入 `数据/发布数据.csv`，沿用同一事项ID。检查字段单位、时间范围和对象粒度；单次任务不填项目累计数。缺失值不得用0代替。
- 本主题完成条件：事实、素材使用范围与发布版本确认。先逐项核对模板中的审核字段，再更新状态；缺少影响验收的证据时保持待确认。

## 本库中的教学记录

数据记录先确认一行代表什么对象、哪段时间与什么单位。原始记录、分类合计和项目汇总分别维护；验收表的期望结果必须与实际结果逐项对应，不能只填写“通过”。
