# 工作管理笔记本 · 使用手册

欢迎使用「工作管理」笔记本。这是一套帮你把零散事务、项目、会议、复盘系统化的通用模板，适合个人职场管理，也适合小团队协作。无论你是想告别"事情总在脑子里打转"，还是想让一周的工作有迹可循，都可以直接复用本结构。

## 一、这套空间能帮你做什么

- **清空脑子**：任何冒出来的事先丢进 `任务/收件箱.md`，不占脑容量。
- **项目有家**：成形项目放进 `项目/`，按状态分桶，进度一眼可见。
- **一周有谱**：周一定计划、周末做复盘，节奏稳定。
- **会议不白开**：会后自动沉淀决策与行动项到 `会议与沟通/`。
- **资料有处放**：客户、产品、灵感、常用链接统一进 `资料与参考/`。

## 二、第一次上手（6 步）

1. 先填 `工作规则/` 四个文件——目标、优先级、状态、协作沟通，这是所有动作的标尺。
2. 把当前杂事倒进 `任务/收件箱.md`。
3. 用「项目规划」技能把成形项目落成 `项目/进行中/<slug>/项目说明.md`。
4. 用「周计划制定」技能生成 `计划与复盘/本周计划.md` 与 `任务/本周任务.md`。
5. 开会后用「会议整理与行动项」技能产出会议记录 + 决策 + 待跟进。
6. 周末用「工作复盘」跑周复盘，月底跑月度复盘。

## 三、给 AI 用的说明

- 所有 Agent 协作规范见 `AGENTS.md`。
- 六个技能在 `.agents/skills/`：工作收集与整理、项目规划、周计划制定、会议整理与行动项、工作复盘、项目归档。
- 五个模板在 `.agents/模板/`：项目说明、任务、周计划、会议记录、周复盘。
- 命名与状态规则见 `项目说明/命名规范.md`；全局地图见 `项目说明/工作区地图.md`。

## 四、状态怎么流转

- **项目**：文件夹在 `项目/进行中 → 等待中 → 已完成 → 已归档` 之间整体移动（整目录流转，不丢子文件）。
- **任务**：以列表项形式在 `任务/收件箱 → 本周任务 → 已完成/` 之间搬移；等别人的放 `等待他人`；周期性的放 `日常例行事项`。

## 五、重要提醒

- `工作规则/` 是硬约束，任何优先级 / 承诺偏离它前请先和用户确认。
- 不删除历史；完成 / 过时的内容归档，不抹除。
- 本模板中的 `示例项目-官网改版` 仅演示格式，请按真实工作重命名或删除。
