# 优先级规则

> 统一优先级判断标准，避免"什么都重要"。所有任务 / 项目排程都按此规则初判与复核。

## 优先级矩阵（紧急 × 重要）
| | 重要 | 不重要 |
| --- | --- | --- |
| 紧急 | P0：立即做（危机 /  deadline 临近） | P1：安排专人 / 快速处理 |
| 不紧急 | P1：计划做（核心目标相关） | P2：有空再做 / 委托 / 舍弃 |

## 分级定义
- **P0**：影响目标达成或对外承诺、今天 / 明天必须动的。
- **P1**：对核心目标有直接贡献，本周内安排。
- **P2**：锦上添花或 exploratory，无 deadline 不主动排。

## 排队规则
- 同优先级按"离 deadline 近的先做"。
- 单日 P0 不超过 <3> 件，超过则向上求助 / 拆解。
- 长期重要但不紧急的事（P1 不紧急）必须进周计划，否则会被紧急事挤掉。

## 红线
- 不因为"别人催得急"就自动升 P0；先对照 `工作目标.md` 判断重要性。
- 不承诺自己排不进的 deadline；承诺前先确认容量。
