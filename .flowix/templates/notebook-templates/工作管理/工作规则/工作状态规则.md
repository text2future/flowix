# 工作状态规则

> 定义项目与任务的状态，以及它们之间如何流转，保证"一眼看清现在在哪、下一步去哪"。

## 项目状态（整目录流转）


| 状态  | 含义       | 所在桶       | 流转条件       |
| --- | -------- | --------- | ---------- |
| 进行中 | 正在推进     | `项目/进行中/` | 立项即进入      |
| 等待中 | 因外部阻塞暂停  | `项目/等待中/` | 出现不可控阻塞    |
| 已完成 | 交付完成、待归档 | `项目/已完成/` | 目标 / 交付物齐备 |
| 已归档 | 长期不动、留档  | `项目/已归档/` | 已完成且稳定一段时间 |


- 流转方式：**整个项目文件夹在四个桶之间移动**（保留全部子文件）。

## 任务状态（桶文件间搬列表项）


| 桶              | 含义             |
| -------------- | -------------- |
| `任务/收件箱.md`    | 未处理、待分类        |
| `任务/本周任务.md`   | 本周要做的动作        |
| `任务/等待他人.md`   | 等别人反馈 / 审批     |
| `任务/日常例行事项.md` | 周期性重复          |
| `任务/已完成/`      | 办完归档（复杂任务单卡成文） |


## 流转纪律

- 收件箱里的项**每周清空一次**：要么做、要么排期、要么丢弃、要么立项。
- 等待他人的项定期回访，超时升级提醒。
- 不删除历史；完成 / 过时走归档，不抹除。
