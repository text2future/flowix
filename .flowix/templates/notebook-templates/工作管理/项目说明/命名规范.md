# 命名规范 — 工作管理笔记本

所有路径与文件命名遵循本规范，保证 Agent 与人都好找、好写、好排序。

## 一、项目（整目录流转）

```
项目/<状态>/<slug>/项目说明.md
```

- `<状态>`：`进行中` / `等待中` / `已完成` / `已归档`。
- `<slug>`：短横线主题名，如 `官网改版`、`q3-产品迭代`。
- 示例：`项目/进行中/官网改版/项目说明.md`
- 项目文件夹内可再放 任务、会议、资料等子文件，随文件夹一起移动。

## 二、任务（文件内列表项 + 可单卡）

- 日常桶文件（固定名）：`任务/收件箱.md`、`任务/本周任务.md`、`任务/等待他人.md`、`任务/日常例行事项.md`
- 已完成归档：`任务/已完成/<YYYYMMDD>-<slug>.md`（复杂任务单卡归档）
- 简单任务：作为列表项写在上述桶文件里。
- 复杂任务：用 `模板/任务.md` 单独成文，可放在对应项目文件夹内。

## 三、计划与复盘

```
计划与复盘/本周计划.md                         # 当前周
计划与复盘/历史周计划/YYYY-Www-周计划.md         # 归档
计划与复盘/周复盘/YYYY-Www-周复盘.md
计划与复盘/月度复盘/YYYY-MM-月度复盘.md
```

- `YYYY-Www`：年-周次，如 `2026-W39`。

## 四、会议与沟通

```
会议与沟通/会议记录/YYYYMMDD-<slug>.md
会议与沟通/决策记录.md        # 跨会议决策台账（累积）
会议与沟通/待跟进事项.md      # 行动项总表（累积）
```

## 五、资料与参考

```
资料与参考/客户与合作方/<名称>.md
资料与参考/产品与业务资料/<主题>.md
资料与参考/研究与灵感/<主题>.md
资料与参考/常用链接.md
```

## 六、工作规则（固定 4 个）

```
工作规则/工作目标.md
工作规则/优先级规则.md
工作规则/工作状态规则.md
工作规则/协作与沟通规则.md
```

## 七、通用约定

- 正文一律 Markdown；二进制素材只放链接与说明，不内嵌。
- 项目是"整目录移动"；任务是在桶文件间搬列表项；不删除历史。
- 同一项目的所有产物尽量挂在项目文件夹内，便于整项目回看。
- 所有 `<slug>` 用短横线，避免空格与中文标点，便于排序与链接。
