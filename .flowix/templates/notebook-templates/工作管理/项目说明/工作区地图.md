# 工作区地图

> 一张图看懂本笔记本每个区域是干什么的、该往哪放东西。配合 `命名规范.md` 使用。

## 顶层结构

```
工作管理/
├── AGENTS.md            # Agent 协作规范（给 AI 看）
├── README.md            # 人类使用手册
├── .agents/             # 技能 + 模板（引擎，不手动改内容）
├── 工作规则/            # 标尺：目标、优先级、状态、协作
├── 项目/                # 按状态分桶的项目文件夹
├── 任务/                # 收件箱、本周、等待他人、例行、已完成
├── 计划与复盘/          # 本周计划、历史周计划、周复盘、月度复盘
├── 会议与沟通/          # 会议记录、决策记录、待跟进事项
├── 资料与参考/          # 客户、产品业务、研究灵感、常用链接
└── 项目说明/            # 工作区地图、命名规范
```

## 各区域一句话

| 区域 | 放什么 | 不放什么 |
| --- | --- | --- |
| `工作规则/` | 目标、优先级矩阵、状态定义、协作约定 | 具体任务 |
| `项目/进行中` | 正在推进的项目文件夹（含 项目说明.md） | 已完成项目 |
| `项目/等待中` | 因外部阻塞暂停的项目 | 纯想法 |
| `项目/已完成` | 交付完成、待归档的项目 | 进行中的 |
| `项目/已归档` | 长期不动、留档的项目 | 活跃项目 |
| `任务/收件箱` | 未处理的杂事（先收集后整理） | 已规划好的 |
| `任务/本周任务` | 本周要做的动作，关联项目 | 长期目标 |
| `任务/等待他人` | 等别人反馈 / 审批的事项 | 自己能做的 |
| `任务/日常例行事项` | 周期性重复的动作 | 一次性任务 |
| `任务/已完成` | 办完的任务归档 | 未办的 |
| `计划与复盘/本周计划` | 当前周的安排 | 历史计划 |
| `计划与复盘/历史周计划` | 过去周计划归档 | 当前周 |
| `计划与复盘/周复盘` | 每周回顾文件 | 月度 |
| `计划与复盘/月度复盘` | 每月回顾文件 | 周度 |
| `会议与沟通/会议记录` | 每次会议的记录文件 | 决策汇总 |
| `会议与沟通/决策记录` | 跨会议的重要决策台账 | 讨论细节 |
| `会议与沟通/待跟进事项` | 会议产生的行动项总表 | 已关闭项 |
| `资料与参考/客户与合作方` | 客户 / 合作方档案 | 内部资料 |
| `资料与参考/产品与业务资料` | 产品、业务文档 | 个人灵感 |
| `资料与参考/研究与灵感` | 调研、想法、灵感 | 正式资料 |
| `资料与参考/常用链接` | 常用系统 / 工具链接 | 长文资料 |

## 流转方向（记不住就看这条）

```
收件箱 →（整理）→ 项目/进行中 或 任务/本周任务
项目/进行中 →（阻塞）→ 项目/等待中 →（恢复）→ 进行中
项目/进行中 →（完成）→ 项目/已完成 →（稳定）→ 项目/已归档
任务/本周任务 →（完成）→ 任务/已完成
会议 → 会议记录 + 决策记录 + 待跟进事项
本周计划 →（周末）→ 周复盘 →（月末）→ 月度复盘
```
