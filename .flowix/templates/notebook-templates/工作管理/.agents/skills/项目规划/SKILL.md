# 项目规划

## 触发条件
- 用户确认要启动一个项目，或「工作收集与整理」标明了成形项目。
- 上游就绪：`工作规则/` 已填（目标、优先级、状态定义）。

## 输入
- 用户提供的项目背景、目标、范围
- `工作规则/工作目标.md`、`优先级规则.md`、`协作与沟通规则.md`

## 输出
- `项目/进行中/<slug>/项目说明.md`（使用 `.agents/模板/项目说明.md`）
- 在 `任务/本周任务.md` 或 `计划与复盘/本周计划.md` 登记首个推进动作
- 若需协作，提示按 `协作与沟通规则.md` 同步相关方

## 工作流
1. 明确项目目标（可衡量）与范围（含 / 不含）。
2. 拆里程碑与关键结果，对齐 `工作目标.md`。
3. 识别风险、相关方、依赖。
4. 套用 `.agents/模板/项目说明.md` 产出，`status` 置为 `进行中`。
5. 把本周可执行的第一步写进周计划 / 本周任务。

## 质量检查清单
- [ ] 目标可衡量，范围清晰（含 / 不含）
- [ ] 里程碑对齐 `工作目标.md`
- [ ] 风险与相关方已识别
- [ ] 已登记首个推进动作
- [ ] 命名符合 `项目说明/命名规范.md`（整目录流转）

## 上游 / 下游
- 上游：`工作收集与整理`（立项来源）
- 下游：`周计划制定`（拆周动作）、`会议整理与行动项`、`项目归档`（完成时）
