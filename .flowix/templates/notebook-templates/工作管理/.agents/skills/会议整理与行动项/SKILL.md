# 会议整理与行动项

## 触发条件
- 用户提供会议录音、笔记或口述，要求整理。
- 上游就绪：会议已发生（或由用户描述）。

## 输入
- 会议素材（录音转写、笔记、口述）
- 相关 `项目/进行中/<slug>/项目说明.md`（如有项目背景）
- `工作规则/协作与沟通规则.md`

## 输出
- `会议与沟通/会议记录/YYYYMMDD-<slug>.md`（使用 `.agents/模板/会议记录.md`）
- 追加重要决策到 `会议与沟通/决策记录.md`
- 追加行动项到 `会议与沟通/待跟进事项.md`（含责任人 / 截止 / 关联项目）

## 工作流
1. 梳理参会人、时间、议程。
2. 提炼讨论要点与结论。
3. 提取决策（入决策记录）与行动项（入待跟进，带责任人 / 截止）。
4. 套用 `.agents/模板/会议记录.md` 产出会议记录。
5. 把行动项同步到对应项目的本周任务（如适用）。

## 质量检查清单
- [ ] 参会人 / 时间 / 议程完整
- [ ] 决策已入 `决策记录.md` 且可追溯
- [ ] 行动项有责任人、截止日、关联项目
- [ ] 行动项已入 `待跟进事项.md`
- [ ] 命名符合规范（YYYYMMDD-<slug>）

## 上游 / 下游
- 上游：`周计划制定`（会议常排入周计划）、`项目规划`
- 下游：`工作复盘`（行动项闭环检查）、`周计划制定`（行动项入周任务）
