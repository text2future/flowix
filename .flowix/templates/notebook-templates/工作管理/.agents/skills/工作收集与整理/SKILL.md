# 工作收集与整理

## 触发条件
- 用户抛来一批未结构化的事项，或要求"收集 / 整理"。
- 上游：无固定上游，本技能是流水线的入口。

## 输入
- 用户提供的原始事项（文本、截图、聊天记录等）
- `工作规则/优先级规则.md`、`工作状态规则.md`（用于分类与初判优先级）

## 输出
- 写入 `任务/收件箱.md`（未分类项先入收件箱）
- 已判断的项分流：
  - 成形项目 → 建议进入「项目规划」（不直接建，先标注）
  - 单任务 → `任务/本周任务.md` 或 `任务/等待他人.md`
  - 参考资料 → `资料与参考/` 对应子目录
- 在收件箱中标记每项状态（待整理 / 已分流）

## 工作流
1. 通读原始事项，逐条识别类型（项目 / 任务 / 资料 / 噪音）。
2. 按 `优先级规则.md` 给任务初判优先级（不承诺，仅标注）。
3. 把未决项写入收件箱，已决项分流到对应桶。
4. 提醒用户：成形项目需跑「项目规划」技能正式立项。

## 质量检查清单
- [ ] 所有 incoming 都进了收件箱或已分流，无遗漏
- [ ] 项目 / 任务 / 资料分类正确
- [ ] 优先级初判依据 `优先级规则.md`
- [ ] 收件箱每项都标了状态
- [ ] 未擅自立项；成形项目已提示走「项目规划」

## 上游 / 下游
- 上游：无（入口）
- 下游：`项目规划`、`周计划制定`、`会议整理与行动项`
