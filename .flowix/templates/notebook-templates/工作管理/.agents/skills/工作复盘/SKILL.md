# 工作复盘

## 触发条件
- 用户要求周复盘（周末）或月度复盘（月末）。
- 上游就绪：对应周期的 `本周计划.md` / 历史周计划、项目状态、待跟进事项已就绪。

## 输入
- `计划与复盘/本周计划.md`（或当月各周计划）
- `项目/进行中/*`、`项目/已完成/*` 状态
- `会议与沟通/待跟进事项.md`（行动项闭环情况）
- `工作规则/工作目标.md`

## 输出
- 周：`计划与复盘/周复盘/YYYY-Www-周复盘.md`（使用 `.agents/模板/周复盘.md`）
- 月：`计划与复盘/月度复盘/YYYY-MM-月度复盘.md`
- 更新项目状态（`进行中 → 已完成` 等）
- 把未闭环行动项滚动到下周 / 下月

## 工作流
1. 对照计划，逐项看达成度与偏差。
2. 盘点项目推进与阻塞（阻塞的标 `等待中`）。
3. 核查待跟进事项闭环，未结的滚动。
4. 提炼亮点、问题与下期改进。
5. 套用模板产出复盘，更新状态。

## 质量检查清单
- [ ] 计划达成度有依据（非凭感觉）
- [ ] 项目状态已更新，阻塞已标等待中
- [ ] 待跟进事项逐条核对闭环
- [ ] 改进项具体、可下期执行
- [ ] 命名符合规范（YYYY-Www / YYYY-MM）

## 上游 / 下游
- 上游：`周计划制定`、`项目规划`、`会议整理与行动项`
- 下游：`项目归档`（已完成项目）、下一轮 `周计划制定`
