# 项目归档

## 触发条件
- 用户确认某项目已交付 / 结束，要求归档。
- 上游就绪：对应 `项目/进行中/<slug>/项目说明.md` 的目标已全部达成。

## 输入
- `项目/进行中/<slug>/项目说明.md`（确认完成）
- `任务/本周任务.md`、`任务/等待他人.md`（是否有遗留）
- `会议与沟通/待跟进事项.md`（是否还有未闭环项）

## 输出
- 移动 `项目/进行中/<slug>/` → `项目/已完成/<slug>/`（先）
- 稳定一段时间后 → `项目/已归档/<slug>/`
- 在 `项目说明.md` 标记 `status: 已完成 / 已归档` 与归档日期
- 清理遗留任务：完成项入 `任务/已完成/`，无主项提示用户

## 工作流
1. 核对项目目标与交付物是否齐备。
2. 检查关联任务与待跟进项是否闭环；未闭环的先处理或转出。
3. 移动整个项目文件夹到 `已完成`（保留全部子文件，整目录流转）。
4. 在 `项目说明.md` 更新状态与日期。
5. 一段时间无变动后，再移到 `已归档`。

## 质量检查清单
- [ ] 项目目标 / 交付物已确认齐备
- [ ] 关联任务与行动项已闭环或转出
- [ ] 整个文件夹已移动到正确状态桶
- [ ] `项目说明.md` 状态与日期已更新
- [ ] 命名与流转符合 `项目说明/命名规范.md`

## 上游 / 下游
- 上游：`工作复盘`（判定完成）、`项目规划`
- 下游：无（终点）；必要时反向「项目规划」重启
