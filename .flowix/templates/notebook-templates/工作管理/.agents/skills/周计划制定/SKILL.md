# 周计划制定

## 触发条件
- 用户要求制定本周计划，或周一例行。
- 上游就绪：`项目/进行中/*` 的项目说明、`任务/收件箱.md`、`任务/本周任务.md` 已就绪。

## 输入
- 各 `项目/进行中/<slug>/项目说明.md`（里程碑与下一步）
- `任务/收件箱.md`（待分流）、`任务/本周任务.md`（上周遗留）
- `工作规则/优先级规则.md`、`工作目标.md`

## 输出
- `计划与复盘/本周计划.md`（使用 `.agents/模板/周计划.md`，覆盖写当前周）
- 刷新 `任务/本周任务.md`（本周动作清单，关联项目）
- 上周 `本周计划.md` 移入 `计划与复盘/历史周计划/YYYY-Www-周计划.md`

## 工作流
1. 汇总所有进行中项目的本周推进点。
2. 从收件箱挑出本周要处理的任务，按优先级排程。
3. 标注会议、例行事项、风险。
4. 套用 `.agents/模板/周计划.md` 产出；同步刷新本周任务。
5. 把上一周计划归档到历史周计划。

## 质量检查清单
- [ ] 覆盖了所有进行中项目的关键推进
- [ ] 本周任务按 `优先级规则.md` 排好
- [ ] 会议 / 例行已纳入
- [ ] 上周计划已归档
- [ ] 命名符合规范（本周计划固定名 + 历史按 YYYY-Www）

## 上游 / 下游
- 上游：`项目规划`、`工作收集与整理`
- 下游：`工作复盘`（周末对照）、`会议整理与行动项`
