# AGENTS.md — 自媒体管理 工作区代理指南

本文件面向在本工作区运行的所有 AI Agent（智能体）。它定义了工作区的目的、结构约定，以及每个技能何时、如何被调用。人类用户请优先阅读 `README.md`。

## 一、工作区定位

这是一个**自媒体 / 内容创作者管理笔记本**，用一套固定目录 + 一组专职 Agent 技能，把「定位 → 选题 → 内容生产 → 多平台改编 → 发布 → 互动 → 数据复盘 → 商业合作」的全流程收敛到一个可复制、可追溯的空间里。

- 目标用户：个人创作者 / 自媒体主理人 / 小团队内容负责人，运营多平台账号。
- 核心资产：账号策略、内容策划与内容包、平台规范、互动与受众、数据与复盘、商业合作、素材。
- 协作方式：每个技能只做一件事，上游产物是下游的输入；**账号策略与平台规范是所有内容共同遵守的标尺**。

## 三、内容生产流水线（标准顺序）

1. **账号定位与内容策略** — 维护 `账号策略/`，定受众、内容支柱、品牌声音与商业边界。
2. **选题评估与排期** — 从 `内容策划/选题池.md` 评估选题，排入 `内容策划/内容日历.md`。
3. **内容包创建** — 为一个选题产出 `内容/<状态>/<slug>/` 下的主内容与素材清单。
4. **多平台内容改编** — 依据 `平台规范/` 把主内容改编成各平台版本。
5. **发布准备与检查** — 按平台清单检查后发布，记录到 `发布记录.md`。
6. **评论与私信整理** — 回收互动，沉淀高价值问题与商业线索。
7. **内容数据复盘** — 发布后按周期看数据，写 `内容复盘.md`、汇总到 `内容表现总览.md`。
8. **商业合作管理** — 跟进合作，产出合作项目与复盘。
9. **月度策略复盘** — 月末汇总数据与洞察，调整账号策略。

> 日常循环是 2→3→4→5→6；数据复盘按周期做（7）；有合作时触发（8）；月度策略复盘（9）每月一次。

## 四、文件与命名约定

- 严格遵循 `项目说明/命名规范.md`。核心规则：
  - 内容包：`内容/<状态>/<YYYY-MM>-<slug>/`（内含 `内容卡片.md` 与各平台稿件）。
  - 内容卡片：内容包内的 `内容卡片.md`（使用 `.agents/模板/内容卡片.md`）。
  - 周 / 月度复盘：`数据与复盘/周度复盘/YYYY-Www-周度复盘.md`、`月度复盘/YYYY-MM-月度复盘.md`。
  - 平台稿件：`内容/<状态>/<slug>/<平台>-<类型>.md`，如 `小红书-笔记.md`。
- 正文用 Markdown；图片 / 视频放 `素材与资料/图片与视频/`，正文只放链接。
- 不删除历史内容；暂停 / 过时内容走 `已暂停` / `已归档`，不抹除。

## 五、Agent 协作原则

- **策略优先**：任何内容都必须先过 `账号策略/`（定位、受众、品牌声音、边界），不偏离调性。
- **平台适配**：改编必须符合对应 `平台规范/`，不直接把一个平台的内容搬到另一个平台。
- **谁的输入谁负责**：调用下游技能前，确认上游产物已就绪且路径正确。
- **只动自己职责内的文件**：内容包创建不擅自改策略；数据复盘不编造数据。
- **留下可追溯的痕迹**：在内容卡片与发布记录中记录做了什么、何时、数据如何。
- **不确定就问**：涉及商务报价、对外承诺、隐私信息发布前，必须获得用户确认。
- **中文输出**：除专有名词外，一律简体中文。
