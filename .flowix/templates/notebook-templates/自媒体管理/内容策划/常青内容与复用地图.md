# 常青内容与复用地图

> 哪些内容值得反复利用 / 更新 / 跨平台复用，一图看清。（示例）

## 常青内容（长期有效，可持续引流）
| 内容 | 平台 | 形式 | 复用方式 |
| --- | --- | --- | --- |
| 向上汇报的 3 个模板 | 公众号 → 小红书 / B站 | 长文 → 图 / 视频 | 每年更新一版 |

## 复用地图
```
一篇深度长文
   ├─ 拆成 3–5 条小红书图文
   ├─ 改成一条 B站 / 抖音脚本
   ├─ 摘成金句卡片
   └─ 打包成电子书 / 课程素材
```

## 更新与刷新
- 常青内容每 6–12 个月回看，更新过时信息，刷新发布时间。
- 表现好的旧内容，重新剪成短视频二次分发。

## 使用说明
- 新选题前先查：能否复用 / 更新已有常青内容，而非全部从零做。
