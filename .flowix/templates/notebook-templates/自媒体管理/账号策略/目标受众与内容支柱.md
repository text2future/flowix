# 目标受众与内容支柱

> 给谁看、给什么内容。所有选题都要对齐这里。（示例）

## 一、受众画像
- **核心人群**：3–8 年经验的一线城市白领 / 基层到中层管理者。
- 特征：有上进心但时间紧；被沟通 / 汇报问题困扰；讨厌空话。
- 痛点：不会汇报、不敢争取、跨部门推不动、内耗严重。
- 他们想要：马上能用的模板、话术、清单。

## 二、内容支柱（3–5 个）
| 支柱 | 说明 | 适配平台 |
| --- | --- | --- |
| 向上沟通 | 汇报、请示、争取资源 | 公众号 / 小红书 / B站 |
| 表达模板 | 话术、邮件、会议发言 | 小红书 / 公众号 |
| 职场效率 | 时间管理、工具 | B站 / 公众号 |
| 成长心态 | 反内耗、职业选择 | 公众号 / 小红书 |

## 三、内容配比建议
- 干货模板 50%｜案例拆解 30%｜心态观点 20%
- 各平台按 `../平台规范/` 侧重。

## 四、使用说明
- 选题评估（见 `../内容策划/选题池.md`）必须能对应至少一个支柱。
- 支柱调整需走「月度策略复盘」。
