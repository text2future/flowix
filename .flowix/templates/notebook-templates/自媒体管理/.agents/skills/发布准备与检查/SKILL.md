# 发布准备与检查

## 触发条件
- 内容包已完成改编，准备发布。
- 上游就绪：内容包内各平台版本、`平台规范/<平台>.md`。

## 输入
- `内容/<状态>/<slug>/` 内各平台稿件
- `平台规范/<平台>.md`（发布前检查项、合规、话题标签）
- `项目说明/隐私与合作规范.md`（隐私、合规红线）

## 输出
- 检查完成的内容包（状态从 `进行中` 移到 `待发布`，发布后移到 `已发布`）
- `发布记录.md`（使用 `.agents/模板/发布记录.md`）：平台、时间、链接、话题、备注

## 工作流
1. 按平台规范逐项检查：标题、错别字、话题、封面尺寸、@与链接、合规。
2. 检查隐私与合作规范：无敏感信息、无未授权内容、合作已标注。
3. 通过后移动内容包到 `待发布` / `已发布`。
4. 填写 `发布记录.md`（含实际发布时间与链接）。
5. 提醒用户：发布为对外动作，需用户确认后执行。

## 质量检查清单
- [ ] 逐平台检查项全部通过
- [ ] 无错别字、无隐私泄露、合规
- [ ] 合作内容已按规范标注
- [ ] 内容包已流转到正确状态目录
- [ ] `发布记录.md` 已填写

## 上游 / 下游
- 上游：`多平台内容改编`
- 下游：`评论与私信整理`、`内容数据复盘`
