# 内容数据复盘

## 触发条件
- 内容发布一段时间后，需要看数据、做复盘。
- 上游就绪：`发布记录.md`、`数据与复盘/数据记录规范.md`。

## 输入
- `内容/<状态>/<slug>/发布记录.md`
- `数据与复盘/数据记录规范.md`（指标与口径）
- 各平台后台数据（用户提供）

## 输出
- `内容/<slug>/内容复盘.md`（使用 `.agents/模板/内容复盘.md`）
- 更新 `数据与复盘/内容表现总览.md`
- 新洞察追加到 `数据与复盘/可复用洞察.md`

## 工作流
1. 按数据记录规范采集：曝光 / 阅读 / 播放、互动、涨粉、转化、完播等。
2. 对照账号基准与同类内容，判断这条是好 / 中 / 差。
3. 分析原因（选题 / 标题 / 封面 / 结构 / 平台 / 时间）。
4. 提炼可复用洞察（什么做法值得重复、什么要避免）。
5. 汇总到表现总览。

## 质量检查清单
- [ ] 数据按统一口径采集，不编造
- [ ] 与基准 / 同类内容对比，不止看绝对值
- [ ] 归因有依据（结合选题 / 形式 / 时间）
- [ ] 洞察具体可复用
- [ ] 已更新表现总览

## 上游 / 下游
- 上游：`发布准备与检查`
- 下游：`月度策略复盘`、`选题评估与排期`（指导下一步）
