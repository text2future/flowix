# 选题评估与排期

## 触发条件
- 用户提出 / 收集了选题，需要评估与排期。
- 上游就绪：`账号策略/`、`内容策划/选题池.md`。

## 输入
- `内容策划/选题池.md`（候选选题）
- `账号策略/目标受众与内容支柱.md`（对齐支柱）
- `数据与复盘/可复用洞察.md`、`内容表现总览.md`（历史表现）
- `内容策划/待验证假设.md`（要验证的假设）

## 输出
- 更新 `内容策划/选题池.md`（标注评估结论：采纳 / 待定 / 弃用）
- 排入 `内容策划/内容日历.md`
- 采纳的选题生成 `选题卡片`（`.agents/模板/选题卡片.md`）

## 工作流
1. 按"是否契合内容支柱、受众需求、平台适配、可执行性"评估。
2. 结合历史数据判断潜力（哪类选题表现好）。
3. 排期：考虑节奏、热点时效、平台组合、产能。
4. 生成选题卡片，更新选题池与内容日历。

## 质量检查清单
- [ ] 每个选题对齐至少一个内容支柱
- [ ] 评估有依据（受众 / 数据 / 假设）
- [ ] 排期考虑产能与热点时效
- [ ] 采纳项已生成选题卡片并排期
- [ ] 弃用项标注原因（不是直接删）

## 上游 / 下游
- 上游：`账号定位与内容策略`
- 下游：`内容包创建`
