# 内容包创建

## 触发条件
- 选题已通过评估并排期，要开始生产内容。
- 上游就绪：`内容策划/内容日历.md` 有本选题，`账号策略/` 已定。

## 输入
- 对应 `选题卡片`（`.agents/模板/选题卡片.md`）
- `账号策略/目标受众与内容支柱.md`、`品牌声音与表达规范.md`
- `素材与资料/`（可取材）

## 输出
- `内容/进行中/<YYYY-MM>-<slug>/内容卡片.md`（使用 `.agents/模板/内容卡片.md`）
- 主稿（如 `主稿.md` 或按首发平台命名）
- 在内容卡片中列出待改编的平台版本清单与所需素材

## 工作流
1. 建内容包目录 `内容/进行中/<YYYY-MM>-<slug>/`。
2. 写 `内容卡片.md`：核心信息（标题 / 钩子 / 3–5 个要点 / CTA）、目标平台、素材清单。
3. 写主稿（首发平台的完整内容）。
4. 标注后续要改编的平台版本。
5. 更新内容卡片状态为"进行中"。

## 质量检查清单
- [ ] 内容包目录命名符合 `内容/<状态>/<YYYY-MM>-<slug>/`
- [ ] 内容卡片含钩子、要点、CTA、平台与素材清单
- [ ] 主稿符合品牌声音
- [ ] 已列待改编平台版本
- [ ] 内容卡片状态已更新

## 上游 / 下游
- 上游：`选题评估与排期`
- 下游：`多平台内容改编`、`发布准备与检查`
