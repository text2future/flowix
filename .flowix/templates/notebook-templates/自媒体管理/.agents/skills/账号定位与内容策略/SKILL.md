# 账号定位与内容策略

## 触发条件
- 新建账号，或需要复盘 / 调整账号策略。
- 上游就绪：无（本技能是策略源头）。

## 输入
- 用户提供的账号方向、擅长领域、目标
- 已有 `账号策略/` 各文件、`素材与资料/竞品与参考账号.md`

## 输出
- `账号策略/账号定位与目标.md`（使用 `.agents/模板/账号定位与目标.md`）
- `账号策略/目标受众与内容支柱.md`
- `账号策略/品牌声音与表达规范.md`
- `账号策略/平台与商业边界.md`

## 工作流
1. 明确"我是谁、给谁看、提供什么价值"（一句话定位）。
2. 定义目标受众画像与 3–5 个内容支柱。
3. 定品牌声音（调性、称谓、能说 / 不能说的）。
4. 定平台矩阵与商业边界（接什么合作、不接什么）。
5. 产出四份策略文档，作为全流程标尺。

## 质量检查清单
- [ ] 定位一句话说清"给谁、提供什么独特价值"
- [ ] 内容支柱 3–5 个，可支撑长期产出
- [ ] 品牌声音具体（有正反例）
- [ ] 商业边界明确（含不接的红线）
- [ ] 四份文档齐备

## 上游 / 下游
- 上游：无（源头）；参考 `素材与资料/竞品与参考账号.md`
- 下游：`选题评估与排期`、`多平台内容改编`、`月度策略复盘`
