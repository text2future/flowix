# 月度策略复盘

## 触发条件
- 月末，或需要调整账号策略方向。
- 上游就绪：`数据与复盘/` 各文件、`商业合作/` 记录。

## 输入
- `数据与复盘/内容表现总览.md`、`可复用洞察.md`、周度复盘
- `商业合作/合作复盘.md`
- `账号策略/账号定位与目标.md`（对照目标）

## 输出
- `数据与复盘/月度复盘/YYYY-MM-月度复盘.md`（使用 `.agents/模板/月度复盘.md`）
- 必要时调整 `账号策略/`（定位、支柱、平台矩阵、商业边界）
- 更新 `内容策划/待验证假设.md`（哪些假设被验证 / 证伪）

## 工作流
1. 汇总本月：产出量、各平台数据、涨粉、商业化、爆款与扑街。
2. 对照账号目标看达成与偏差。
3. 提炼结构性洞察（哪类内容 / 平台在起势，哪类在衰退）。
4. 调整下月策略与内容重心；更新待验证假设。
5. 产出月度复盘。

## 质量检查清单
- [ ] 数据全面（内容 / 粉丝 / 商业三维）
- [ ] 对照账号目标，偏差有归因
- [ ] 洞察上升到策略层面，非单篇
- [ ] 策略调整具体、可执行
- [ ] 假设已验证 / 更新

## 上游 / 下游
- 上游：`内容数据复盘`、`商业合作管理`
- 下游：`账号定位与内容策略`（策略迭代）、`选题评估与排期`
