# 商业合作管理

## 触发条件
- 有新合作线索，或现有合作需要推进。
- 上游就绪：`商业合作/合作报价与边界.md`、`账号策略/平台与商业边界.md`。

## 输入
- 合作需求（品牌、产品、要求、预算）
- `商业合作/合作报价与边界.md`（报价与不接的红线）
- `账号策略/平台与商业边界.md`
- 来自 `互动与受众/私信与合作线索.md` 的线索

## 输出
- `商业合作/进行中/<slug>/合作项目.md`（使用 `.agents/模板/合作项目.md`）
- 完成后移至 `商业合作/已完成/`
- `商业合作/合作复盘.md`（效果与经验）

## 工作流
1. 评估合作：是否契合账号调性与受众、是否符合边界（不接的红线）。
2. 报价对照报价表；报价与承诺对外前必须用户确认。
3. 立项：写合作项目（交付物、时间、报价、要求）。
4. 执行：产出商业内容（仍需按账号策略保持调性，并按规范标注"广告 / 赞助"）。
5. 完成 → 移至已完成 → 写合作复盘。

## 质量检查清单
- [ ] 已评估是否契合账号与边界
- [ ] 报价符合报价与边界表；对外报价已确认
- [ ] 项目信息完整（交付、时间、报价、要求）
- [ ] 商业内容合规标注
- [ ] 完成后已复盘

## 上游 / 下游
- 上游：`评论与私信整理`（线索）、`账号定位与内容策略`（边界）
- 下游：`内容包创建`（做商单内容）、`月度策略复盘`
