# 评论与私信整理

## 触发条件
- 内容发布后，需要回收互动。
- 上游就绪：已发布内容、`互动与受众/互动处理规则.md`。

## 输入
- 平台评论 / 私信（用户导出或粘贴）
- `互动与受众/` 现有文件
- `账号策略/目标受众与内容支柱.md`（判断相关性）

## 输出
- 追加到 `互动与受众/高价值评论与问题.md`
- 追加到 `互动与受众/常见问题.md`（高频问题）
- 商业线索归入 `互动与受众/私信与合作线索.md`（并对接 `商业合作/合作线索.md`）
- 用户需求 / 痛点点入 `互动与受众/用户反馈与需求.md`

## 工作流
1. 按互动处理规则分类：高价值问题、常见问题、商业线索、负面反馈、噪音。
2. 高价值问题 → 变成后续选题（对接 `内容策划/选题池.md`）。
3. 商业线索 → 登记并提示用户跟进。
4. 需求与痛点 → 记录，供策略复盘参考。
5. 评论区负面 / 争议按规则处理（不删除理性批评，回应对外需用户确认）。

## 质量检查清单
- [ ] 分类清晰，无遗漏
- [ ] 高价值问题已标注可转选题
- [ ] 商业线索已登记并提示跟进
- [ ] 常见问题已归档，便于做 Q&A 内容
- [ ] 涉及回应 / 发布的对外动作已经用户确认

## 上游 / 下游
- 上游：`发布准备与检查`
- 下游：`选题评估与排期`（问题转选题）、`商业合作管理`
