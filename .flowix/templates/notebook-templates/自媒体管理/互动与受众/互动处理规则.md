# 互动处理规则

> 评论 / 私信的处理原则与响应规则。（示例）

## 分类与处理
| 类型 | 处理 |
| --- | --- |
| 高价值问题 | 登记 → 可转选题 |
| 常见问题 | 标准回复 / 置顶 |
| 商业线索 | 登记 → 对接商业合作 |
| 理性批评 | 不删除，评估后采纳 |
| 恶意 / 广告 | 按平台规则举报 / 删除 |

## 响应原则
- 不与人争吵；争议话题冷处理或按边界回应。
- 对外回应（尤其涉及合作、争议）必须用户确认后再发。
- 保护隐私：截图 / 转述评论时对他人信息脱敏。

## 时效
- 商业线索：24h 内回复意向。
- 普通评论：48h 内抽空回。

## 与技能的关系
- 「评论与私信整理」按本规则分类与沉淀。
