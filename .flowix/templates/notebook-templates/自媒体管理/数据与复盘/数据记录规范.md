# 数据记录规范（指标口径）

> 记录哪些指标、口径怎么定义。保证不同时间的复盘可比较。（示例）

## 一、记录哪些指标
| 维度 | 指标 | 说明 |
| --- | --- | --- |
| 曝光 | 曝光 / 展现 | 被看到次数 |
| 消费 | 阅读 / 播放、完播率 | 内容被消费 |
| 互动 | 点赞、收藏、评论、转发 / 分享 | |
| 增长 | 涨粉、取关 | 净增 |
| 转化 | 点击链接、私信、下单 | 商业相关 |

## 二、口径定义
- 数据采集时间点：发布后 **24h / 72h / 7 天** 各记一次（便于看增长曲线）。
- 平台差异：各平台指标名不同，统一映射到上表维度。
- "爆款"定义：互动率 > 账号均值 3 倍，或曝光 > 均值 5 倍。

## 三、记录位置
- 单条：内容包内 `内容复盘.md`。
- 汇总：`内容表现总览.md`。
- 文件命名 / 存放见 `../项目说明/数据记录规范.md`。

## 四、原则
- 不编造、不美化数据；差数据同样记录。
- 同口径对比，跨时间可比。
