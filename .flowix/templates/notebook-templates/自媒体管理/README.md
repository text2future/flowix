# 自媒体管理笔记本 · 使用手册

欢迎使用「自媒体管理」笔记本。这是一套为内容创作者准备的工作区：把定位、选题、内容生产、多平台改编、发布、互动、数据复盘、商业合作统一管理，让"今天发什么、数据怎么样、下个月做什么"都有据可依。适合个人创作者、多平台运营者，以及带小团队的内容负责人。

## 一、这套空间能帮你做什么

- **定位不漂**：受众、内容支柱、品牌声音统一放 `账号策略/`，不会越写越乱。
- **选题不枯竭**：`内容策划/选题池.md` + 内容日历，永远有存货、有排期。
- **内容可流转**：每条内容是一个"内容包"，在 `内容/` 的状态目录间流转，多平台版本收在一处。
- **平台有规范**：每个平台的调性、尺寸、规则写在 `平台规范/`，改编有依据。
- **互动变线索**：高价值评论、私信里的合作线索沉淀到 `互动与受众/`。
- **数据能复用**：复盘不只是看数字，还沉淀成 `可复用洞察.md` 指导下一步。
- **合作有台账**：从线索到完成，商业合作全程可追溯。

## 二、第一次上手（7 步）

1. 用「账号定位与内容策略」填好 `账号策略/` 四个文件——这是所有内容的标尺。
2. 把灵感、看到的好选题先堆进 `内容策划/选题池.md`。
3. 用「选题评估与排期」评估并排进 `内容策划/内容日历.md`。
4. 用「内容包创建」为选题建 `内容/进行中/<slug>/`，写 `内容卡片.md` 与主稿。
5. 用「多平台内容改编」按 `平台规范/` 产出各平台版本。
6. 用「发布准备与检查」检查后发布，记 `发布记录.md`。
7. 周期性用「内容数据复盘」「月度策略复盘」，有合作时用「商业合作管理」。

## 三、目录地图


| 区域       | 放什么                                  |
| -------- | ------------------------------------ |
| `账号策略/`  | 账号定位与目标、目标受众与内容支柱、品牌声音与表达规范、平台与商业边界  |
| `内容策划/`  | 选题池、内容日历、专题与系列、常青内容与复用地图、待验证假设       |
| `内容/`    | 进行中 / 待发布 / 已发布 / 已暂停 / 已归档 的内容包     |
| `平台规范/`  | 公众号、小红书、抖音、B站、X、其他平台                 |
| `互动与受众/` | 高价值评论与问题、私信与合作线索、常见问题、用户反馈与需求、互动处理规则 |
| `数据与复盘/` | 数据记录规范、内容表现总览、周度复盘、月度复盘、内容实验、可复用洞察   |
| `商业合作/`  | 合作线索、进行中、已完成、合作报价与边界、合作复盘            |
| `素材与资料/` | 品牌素材、封面与模板、图片与视频、行业资料、竞品与参考账号、常用链接   |
| `项目说明/`  | 工作区地图、命名规范、数据记录规范、隐私与合作规范            |


## 四、命名与状态约定

**命名**

- 内容包：`内容/<状态>/<YYYY-MM>-<slug>/`（如 `内容/进行中/2026-09-向上汇报的3个模板/`）。
- 平台稿件：内容包内 `<平台>-<类型>.md`，如 `公众号-正文.md`、`小红书-笔记.md`。
- 周 / 月度复盘：`数据与复盘/周度复盘/YYYY-Www-周度复盘.md`、`月度复盘/YYYY-MM-月度复盘.md`。

**状态（内容包整目录流转）**

- `进行中 → 待发布 → 已发布`；中断 → `已暂停`；长期不用 → `已归档`。
- 流转时**整个内容包文件夹一起移动**，不丢平台版本与素材。

## 五、给 AI 用的说明

- 所有 Agent 协作规范见 `AGENTS.md`。
- 九个技能在 `.agents/skills/`：账号定位与内容策略、选题评估与排期、内容包创建、多平台内容改编、发布准备与检查、评论与私信整理、内容数据复盘、商业合作管理、月度策略复盘。
- 七个模板在 `.agents/模板/`：账号定位与目标、内容卡片、选题卡片、发布记录、内容复盘、合作项目、月度复盘。

## 六、重要提醒

- **策略与平台规范是硬约束**，改编内容前先对照 `账号策略/品牌声音与表达规范.md` 与 `平台规范/`。
- 涉及隐私、合作报价、对外承诺，必须获得确认后再对外。
- 本模板中的示例账号「半熟职场」与示例内容仅演示格式，请按你的真实账号替换。
