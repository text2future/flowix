# X（Twitter）· 平台规范

> 本平台的内容调性、形式与发布检查项。改编与发布前对照。（示例）

## 平台定位
- 短内容、观点输出、国际化 / 行业影响力。

## 内容形式
- 单条：短句 + 观点；长推（Thread）串干货。
- Thread 结构：钩子 → 分点 → 收尾 CTA。

## 语言与风格
- 按目标受众选择中文 / 英文；英文注意地道表达。
- 少 hashtag，观点要锋利。

## 发布检查项
- [ ] 单条控制篇幅，观点清晰
- [ ] Thread 首条有强钩子
- [ ] 无敏感 / 违规内容
- [ ] 配图 / 链接有效

## 备注
- 若面向海外，注意时区与发布时间。
