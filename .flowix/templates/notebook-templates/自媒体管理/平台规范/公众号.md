# 公众号 · 平台规范

> 本平台的内容调性、形式与发布检查项。改编与发布前对照。（示例）

## 平台定位
- 深度长文、沉淀信任、承接转化（引流 / 课程）。

## 内容形式
- 篇幅：1500–3000 字。
- 结构：钩子开头 → 分点论述 → 总结 → CTA。
- 排版：小标题清晰、重点加粗、段落短。

## 标题与封面
- 标题公式：利益点 + 数字 / 反差。
- 封图：2.35:1，文字精简可读。

## 发布检查项
- [ ] 无错别字、标点规范
- [ ] 标题不超平台字数限制
- [ ] 摘要（前 120 字）有钩子
- [ ] 已插入 CTA / 引导
- [ ] 原创声明 / 转载规范
