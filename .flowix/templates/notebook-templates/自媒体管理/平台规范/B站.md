# B站 · 平台规范

> 本平台的内容调性、形式与发布检查项。改编与发布前对照。（示例）

## 平台定位
- 中长视频、建立人设与信任、粉丝粘性高。

## 内容形式
- 时长：5–15 分钟。
- 结构：开场抛问题 → 干货展开 → 案例 → 总结 CTA。
- 风格：信息量大、有个人观点、节奏不拖。

## 标题与封面
- 标题：利益点 + 好奇；封面文字 6–10 字。
- 分区 / 标签贴准，利于推荐。

## 发布检查项
- [ ] 脚本有完整起承转合
- [ ] 开头 15 秒给到价值承诺
- [ ] 封面清晰、标题不标题党过度
- [ ] 简介含时间轴 / 相关链接
- [ ] 三连引导（点赞 / 投币 / 收藏）

## 复用
- 长视频可再剪短视频发抖音；图文稿可改脚本。
