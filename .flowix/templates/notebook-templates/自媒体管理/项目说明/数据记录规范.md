# 数据记录规范（元规范）

> 本文件规定**数据文件怎么存、怎么命名、什么时候更新**；具体**记录哪些指标、口径怎么定**见 `../数据与复盘/数据记录规范.md`（指标口径规范）。两者配合使用，避免重复。

## 一、数据放在哪
| 数据 | 位置 |
| --- | --- |
| 单条内容数据 | 内容包内 `内容复盘.md` |
| 跨内容汇总 | `../数据与复盘/内容表现总览.md` |
| 周度数据 | `../数据与复盘/周度复盘/YYYY-Www-周度复盘.md` |
| 月度数据 | `../数据与复盘/月度复盘/YYYY-MM-月度复盘.md` |
| 实验数据 | `../数据与复盘/内容实验/<实验名>.md` |

## 二、命名与频率
- 周度：`YYYY-Www-周度复盘.md`，每周一次。
- 月度：`YYYY-MM-月度复盘.md`，每月一次。
- 单条数据：建议在发布后 24h / 72h / 7 天各补记一次（口径见指标规范）。

## 三、更新责任
- 由「内容数据复盘」与「月度策略复盘」技能负责采集与写入。
- 数据变更需有记录（改了哪个数、为什么）。

## 四、原则
- 不编造、不美化；差数据同样如实记录。
- 同口径对比，保证跨时间可比。
