# 工作区地图

> 一张图看懂本笔记本每个区域干什么、该往哪放。（配合 `命名规范.md`）

## 顶层结构
```
自媒体管理/
├── AGENTS.md            # Agent 协作规范（给 AI 看）
├── README.md            # 人类使用手册
├── .agents/             # 技能 + 模板（引擎）
├── 账号策略/            # 定位目标、受众支柱、品牌声音、平台与商业边界
├── 内容策划/            # 选题池、内容日历、专题系列、常青复用、待验证假设
├── 内容/                # 进行中/待发布/已发布/已暂停/已归档 的内容包
├── 平台规范/            # 公众号、小红书、抖音、B站、X、其他平台
├── 互动与受众/          # 高价值评论、私信线索、常见问题、用户需求、互动规则
├── 数据与复盘/          # 数据记录规范、表现总览、周度/月度复盘、内容实验、可复用洞察
├── 商业合作/            # 合作线索、进行中/已完成、报价与边界、合作复盘
├── 素材与资料/          # 品牌素材、封面模板、图片视频、行业资料、竞品、常用链接
└── 项目说明/            # 工作区地图、命名规范、数据记录规范、隐私与合作规范
```

## 各区域一句话

| 区域 | 放什么 | 不放什么 |
| --- | --- | --- |
| `账号策略/` | 定位、受众、品牌声音、边界（最高标尺） | 具体内容 |
| `内容策划/` | 选题、日历、系列、常青、假设 | 成稿 |
| `内容/` | 内容包（含平台版本） | 策略 |
| `平台规范/` | 各平台规则与最佳实践 | 具体内容 |
| `互动与受众/` | 评论、私信、问题、需求 | 内容草稿 |
| `数据与复盘/` | 数据、复盘、实验、洞察 | 内容正文 |
| `商业合作/` | 合作线索与项目 | 普通内容 |
| `素材与资料/` | 品牌 / 图片 / 行业 / 竞品 / 链接 | 成稿 |
| `项目说明/` | 规则说明 | 运营内容 |

        ↘ 内容/已暂停        ↘ 内容/已归档
（整目录移动，多平台版本与素材一起走）
