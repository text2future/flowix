# 命名规范 — 自媒体管理笔记本

所有路径与文件命名遵循本规范，保证 Agent 与人都好找、好写、好排序。

## 一、内容包（整目录流转）

```
内容/<状态>/<YYYY-MM>-<slug>/
```
- `<状态>`：`进行中` / `待发布` / `已发布` / `已暂停` / `已归档`。
- 示例：`内容/进行中/2026-09-向上汇报的3个模板/`
- 包内固定含 `内容卡片.md`；平台稿件按需生成。

## 二、平台稿件

```
内容/<状态>/<slug>/<平台>-<类型>.md
```
- 示例：`公众号-正文.md`、`小红书-笔记.md`、`B站-脚本.md`、`抖音-口播稿.md`。

## 三、发布 / 复盘（包内或目录内）

- 包内：`发布记录.md`、`内容复盘.md`。
- 周度：`数据与复盘/周度复盘/YYYY-Www-周度复盘.md`
- 月度：`数据与复盘/月度复盘/YYYY-MM-月度复盘.md`

## 四、选题与策划

```
内容策划/选题池.md、内容日历.md、常青内容与复用地图.md、待验证假设.md
内容策划/专题与系列/<专题名>.md
```

## 五、平台规范（固定名）

```
平台规范/公众号.md、小红书.md、抖音.md、B站.md、X.md、其他平台.md
```

## 六、商业合作

```
商业合作/合作线索.md、合作报价与边界.md、合作复盘.md
商业合作/进行中/<YYYY-MM>-<品牌或slug>/合作项目.md
商业合作/已完成/<品牌或slug>/
```

## 七、素材与资料

```
素材与资料/品牌素材/<类型>-<名称>.<ext>
素材与资料/封面与模板/<用途>-<平台>.<ext>
素材与资料/图片与视频/<用途>-<名称>.<ext>
素材与资料/行业资料/<主题>-<来源>.md
素材与资料/竞品与参考账号.md、常用链接.md
```

## 八、内链约定

- 文档之间互相引用，统一使用**工作区相对路径**（从 `自媒体管理/` 起写），如 `账号策略/品牌声音与表达规范.md`、`平台规范/小红书.md`。
- 好处：换设备 / 分享 / 迁移时链接不失效。

## 九、通用约定

- 正文一律 Markdown；图片 / 视频放 `素材与资料/图片与视频/`，正文只放链接。
- 不删除历史内容；暂停 / 过时走 `已暂停` / `已归档`。
- `<slug>` 用短横线，避免空格与标点，便于排序与链接。
