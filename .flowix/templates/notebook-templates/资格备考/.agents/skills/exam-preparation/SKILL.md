## 推进本主题

本主题流程：考纲分析 → 能力诊断 → 分段学习 → 模拟测试 → 查漏补缺。

1. **考纲分析**：确认适用考纲、科目范围和考试安排。
2. **能力诊断**：用分模块练习识别薄弱知识与错因。
3. **分段学习**：按计划学习与练习，记录题数、正确率和疑问。
4. **模拟测试**：按限定时间完成模拟，区分知识、审题与时间分配问题。
5. **查漏补缺**：订正后间隔重练，检查是否掌握并调整后续安排。

- 任务入口：`进度视图.csv`。按事项ID查找记录，展示给用户时使用任务名称。
- 决策与依据：`科目/计划表.csv`、`科目/资料/资料清单.csv`。
- 新任务：复制 `公共/学习模块记录.md`，在 `科目/` 下用可读的任务名称建目录；场次、批次等重复任务加日期。
- 填写案例与真实任务时沿用空白模板的标题和字段，不另造一套简化结构。字段不适用写明原因；资料缺失时说明缺口及影响。过程写已发生的动作，产物保存到任务目录并登记实际路径。
- 结果写入 `数据/练习与模拟.csv`，沿用同一事项ID。检查字段单位、时间范围和对象粒度；单次任务不填项目累计数。缺失值不得用0代替。
- 本主题完成条件：官方考纲与考试日期核对。先逐项核对模板中的审核字段，再更新状态；缺少影响验收的证据时保持待确认。

## 本库中的教学记录

`科目/财务会计模块练习订正/任务记录.md` 与 `科目/财务会计模块练习订正/财务会计练习订正.md` 展示一次任务的记录及产物。其中人物和数据为模拟；未经用户要求，不把模拟数据当作真实事实或继续虚构实际结果。外部发布、支付和联系按用户授权执行。

数据记录先确认一行代表什么对象、哪段时间与什么单位。原始记录、分类合计和项目汇总分别维护；验收表的期望结果必须与实际结果逐项对应，不能只填写“通过”。
