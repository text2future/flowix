# 课堂复盘

## 触发条件
- 用户要求对某单元做复盘，或学期末做学期复盘。
- 上游就绪：对应 `单元设计.md`、`课时/*.md` 已处于 `已授课` 状态。

## 输入
- `第N单元-<slug>/单元设计.md` 与 `课时/*.md`
- 课堂实录 / 学生作业反馈（用户提供或来自 `资源库/作业与评价/`）
- `教研与复盘/教学问题库.md`（已有问题，避免重复）

## 输出
- 单元级：`第N单元-<slug>/单元复盘.md`（使用 `.agents/模板/单元复盘.md`）
- 学期级：`学期课程/<学期>/学期复盘.md`
- 反思沉淀：`教研与复盘/课堂反思/YYYYMMDD-<slug>.md`
- 问题入账：把典型问题追加到 `教研与复盘/教学问题库.md`
- 同步把 `单元设计.md` 状态更新为 `已复盘`

## 工作流
1. 对照单元目标，评估达成度（哪些达成、哪些未达成）。
2. 记录亮点与典型学生表现。
3. 梳理问题：区分"本单元特有"与"跨单元共性"，共性入教学问题库。
4. 给出下一轮改进动作。
5. 套用 `.agents/模板/单元复盘.md` 产出，并更新状态。

## 质量检查清单
- [ ] 目标达成度有证据（作业 / 测验 / 观察），非凭感觉
- [ ] 问题已区分归属，共性已入教学问题库
- [ ] 改进动作具体、可下次执行
- [ ] 已在 `教研与复盘/课堂反思/` 留痕
- [ ] 单元 `status` 已更新为 `已复盘`

## 上游 / 下游
- 上游：`单元整体设计`、`课时教学设计`、`作业与评价设计`
- 下游：下一轮 `单元整体设计`（改进）、`教研与复盘`（长期沉淀）
