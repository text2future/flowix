# 单元整体设计

## 触发条件
- 用户给出单元主题、教材章节范围，或要求"设计第一单元 / 整体设计某单元"。
- 上游就绪：`课程规则/` 与 `学期课程/<学期>/学期课程计划.md` 已存在。

## 输入
- `课程规则/课程标准要点.md`、`教材与版本说明.md`、`学情概览.md`、`评价与作业原则.md`、`教学进度规则.md`
- `学期课程/<学期>/学期课程计划.md`
- 用户提供的单元主题 / 章节范围

## 输出
- `学期课程/<学期>/第N单元-<slug>/单元设计.md`（使用 `.agents/模板/单元设计.md`）
- 在 `学期课程计划.md` 的"单元清单"中登记本单元（含路径与状态）

## 工作流
1. 读课程规则，提取本单元对应的课标要求、核心概念、评价指向。
2. 结合学情与教材，确定单元大概念 / 核心素养目标。
3. 拆解课时安排，列出每课时主题与容量，对齐教学进度规则。
4. 设计单元评价方案（表现性任务 / 测验 / 作业）。
5. 套用 `.agents/模板/单元设计.md` 产出文档，`status` 置为 `设计中`。

## 质量检查清单
- [ ] 单元目标可观测、可评价，且对应课标条目
- [ ] 大概念 / 核心素养表述清晰，贯穿课时
- [ ] 课时拆分符合教学进度规则，总量不超标
- [ ] 单元评价方案明确，与课时设计呼应
- [ ] 已在学期计划登记；路径命名符合 `项目说明/命名规范.md`

## 上游 / 下游
- 上游：`课程规则/*`、`学期课程计划.md`
- 下游：`课时教学设计`（拆课时）、`作业与评价设计`（配作业）、`课堂复盘`（授后）
