# 课时教学设计

## 触发条件
- 用户要求撰写某个课时的教学设计，且对应 `第N单元-<slug>/单元设计.md` 已存在。
- 上游就绪：`单元设计.md` 已完成，含本课时在单元中的定位。

## 输入
- `第N单元-<slug>/单元设计.md`（单元目标、课时安排、评价指向）
- `课程规则/学情概览.md`、`评价与作业原则.md`
- 用户指定的课时序号与主题

## 输出
- `第N单元-<slug>/课时/第N课时-<slug>.md`（使用 `.agents/模板/课时设计.md`）
- 在 `单元设计.md` 的"课时安排"表中回填本课时路径与状态

## 工作流
1. 明确本课时的单元定位与子目标（承接单元大概念）。
2. 确定重难点，基于学情选择教学策略与活动。
3. 设计教学过程：导入 → 新授 → 活动 / 探究 → 小结 → 作业。
4. 引用或协同 `作业与评价设计` 产出本课时的作业与评价。
5. 套用 `.agents/模板/课时设计.md` 产出，`status` 置为 `备课中`。

## 质量检查清单
- [ ] 课时目标承接单元目标，且可观测
- [ ] 重难点基于学情，策略匹配目标
- [ ] 教学过程环节完整、时间分配合理
- [ ] 作业 / 评价已引用 `资源库/作业与评价/` 或明确待设计
- [ ] 已在单元设计课时表登记；命名符合规范

## 上游 / 下游
- 上游：`单元整体设计`（单元设计.md）
- 下游：`作业与评价设计`（配作业）、`课堂复盘`（授后反思）
