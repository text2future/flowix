# 作业与评价设计

## 触发条件
- 用户要求设计某课时 / 单元的作业、练习、测验或评价量规。
- 上游就绪：对应的 `单元设计.md` 或 `课时设计.md` 已存在（提供目标与评价指向）。

## 输入
- 目标文档：`单元设计.md` 或 `课时设计.md`
- `课程规则/评价与作业原则.md`、`课程标准要点.md`

## 输出
- `资源库/作业与评价/<单元或课时>-作业.md`（作业内容 + 参考答案 / 量规）
- 在对应 `课时设计.md` 的"作业与评价"区回填引用链接
- 如为单元级，也在 `单元设计.md` 的评价方案中登记

## 工作流
1. 读目标文档，提取本课 / 本单元要达成的目标与素养。
2. 按 `评价与作业原则.md` 设计分层作业（基础 / 提升 / 拓展）或表现性任务。
3. 写明评价标准 / 量规与批改方式。
4. 归档到 `资源库/作业与评价/`，并在课时 / 单元设计中引用。

## 质量检查清单
- [ ] 作业 / 评价直接对应目标，不超标、不偏题
- [ ] 符合学校作业量与分层要求（见评价与作业原则）
- [ ] 评价标准明确、可操作（最好有量规）
- [ ] 已在课时 / 单元设计中引用，路径正确
- [ ] 命名符合 `项目说明/命名规范.md`

## 上游 / 下游
- 上游：`单元整体设计`、`课时教学设计`
- 下游：`课堂复盘`（依据作业反馈做改进）
