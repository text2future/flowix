# 作业与评价

本目录归档由「作业与评价设计」技能产出的作业、测验、评价量规，便于跨单元复用。

## 存放规则
- 命名：`<单元或课时>-作业.md`，如 `示例单元-作业.md`、`第一单元-第1课时-作业.md`。
- 内容：作业题干 + 参考答案 / 量规 + 批改说明。
- 按 `课程规则/评价与作业原则.md` 做分层（基础 / 提升 / 拓展）。

## 与流水线关系
- `作业与评价设计` 技能在此产出，并在对应 `课时设计.md` / `单元设计.md` 中引用。
- `课堂复盘` 可依据作业反馈改进下一轮设计。

## 复用
- 同主题作业可直接复制改名复用，避免重复造轮子。
