# 课件与素材

本目录归档各单元 / 课时的课件、图片、音视频等二进制教学素材。

## 存放规则
- 命名：`<描述>.<ext>`，如 `第一单元-导入PPT.pptx`、`分数模型.png`。
- 归属：素材尽量放在对应单元目录下更易找；跨单元通用素材放此处。
- 正文（Markdown）只放链接与说明，不内嵌大文件。

## 与流水线关系
- `课时教学设计` 产出的课件，授课后归档到此。
- 课时设计文档通过相对路径引用，如 `../../../资源库/课件与素材/xxx.pptx`。

## 维护
- 大文件建议压缩或外链；定期清理重复版本。
