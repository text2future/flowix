# 课程设计笔记本 · 使用手册

欢迎使用「课程设计」笔记本。这是一套帮你把备课、授课、复盘系统化的模板空间。无论你是单科教师做个人备课，还是教研组长带团队共建课程，都可以直接复用本结构。

## 一、这套空间能帮你做什么

- **不靠脑子记**：课标要点、教材版本、学情、学校要求、评价原则统一收在 `课程规则/`，所有设计都从这里取标尺。
- **单元→课时一层层拆**：每个单元一个目录，内含单元设计、课时设计、单元复盘，关系清楚、可回看。
- **作业与评价有归档**：每次设计的作业、测验、量规都进 `资源库/作业与评价/`，下次直接复用。
- **复盘留下沉淀**：课堂反思、听评课、教学问题库进 `教研与复盘/`，越教越有积累。

## 二、第一次上手（5 步）

1. 先填 `课程规则/` 下的 7 个文件——这是所有设计的依据，最值得认真写。
2. 在 `学期课程/<学期>/学期课程计划.md` 列出本学期单元清单与进度。
3. 对每个单元跑「单元整体设计」技能，生成 `第N单元-<slug>/单元设计.md`。
4. 用「课时教学设计」技能把单元拆成课时，生成 `课时/第N课时-<slug>.md`；用「作业与评价设计」配作业。
5. 授课后跑「课堂复盘」技能，生成 `单元复盘.md`，并把反思写进 `教研与复盘/`。

## 三、给 AI 用的说明

- 所有 Agent 协作规范见 `AGENTS.md`。
- 四个技能在 `.agents/skills/`：单元整体设计、课时教学设计、作业与评价设计、课堂复盘。
- 三个模板在 `.agents/模板/`：单元设计.md、课时设计.md、单元复盘.md。
- 命名与状态规则见 `项目说明/命名规范.md`。

## 四、状态怎么看

单元与课时**不靠移动文件夹来表示进度**，而是在文档 frontmatter 里用 `status` 字段标记：

- 单元：`设计中 → 已授课 → 已复盘 → 已归档`
- 课时：`备课中 → 已授课 → 已反思`

这样课时、资源都挂在单元目录下，不会因为"流转"而丢失文件。

## 五、重要提醒

- `课程规则/` 是硬约束，任何设计偏离它前请先和用户确认。
- 不要删除历史设计与复盘，它们是你最宝贵的个人教研资产。
- 本模板中的 `示例单元` 仅演示格式，请按真实学科重命名或删除。
