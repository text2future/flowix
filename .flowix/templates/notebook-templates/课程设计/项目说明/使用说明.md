# 使用说明 — 课程设计笔记本

## 一、这个笔记本是给谁用的

- 单科教师：把一学期的备课、授课、复盘装进一个可回看的空间。
- 教研组长：带团队共建单元 / 课时设计，沉淀优秀课例与教研问题。
- 师范生 / 参赛教师：快速搭建结构化的教学设计作品集。

## 二、边界与范围

**本笔记本负责：**

- 课程标准、教材、学情、评价要求的归集（课程规则）。
- 学期 / 单元 / 课时的教学设计产出与归档。
- 作业、评价工具的设计与复用。
- 课堂复盘与教研问题的沉淀。

**本笔记本不负责（建议另建空间）：**

- 学生成绩系统的录入与统计（可用 `资源库/作业与评价/` 存放分析，但不做成绩库）。
- 行政排课、考勤等教务事务。
- 与教学无关的个人笔记。

## 三、推荐工作节奏


| 阶段  | 动作          | 主要技能             |
| --- | ----------- | ---------------- |
| 学期初 | 填课程规则、写学期计划 | —                |
| 单元前 | 单元整体设计      | 单元整体设计           |
| 课前  | 课时设计 + 作业设计 | 课时教学设计 / 作业与评价设计 |
| 课后  | 资源归档 + 单元复盘 | 课堂复盘             |
| 期末  | 学期复盘        | 课堂复盘             |


## 四、和前两个模板的关系

本笔记本与 `公众号写作`、`股票基金投资管理` 同属 `notebook-template/` 下的项目模板，采用同一套设计语言：专职技能 + 可复用模板 + 状态化目录 + 根文档。新增项目直接在 `notebook-template/` 下同级新建即可。
