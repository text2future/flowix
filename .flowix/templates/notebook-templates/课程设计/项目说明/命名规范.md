# 命名规范 — 课程设计笔记本

所有路径与文件命名遵循本规范，保证 Agent 与人都好找、好写、好排序。

## 一、学期目录

```
学期课程/<学年>学年<学期>/
```

- 学年格式：`YYYY-YYYY`（起止年）。
- 学期：上学期 / 下学期。
- 示例：`学期课程/2026-2027学年上学期/`

## 二、单元目录

```
学期课程/<学期>/第N单元-<slug>/
```

- `N` 用中文数字：第一、第二……（与教材册次一致）。
- `<slug>` 用单元主题短名，中文即可，如 `数与代数`、`小说单元`。也可拼音短横线，如 `shu-xue`。
- 示例：`学期课程/2026-2027学年上学期/第一单元-数与代数/`
- 单元目录内固定包含：`单元设计.md`、`课时/`、`单元复盘.md`。

## 三、课时文件

```
单元目录/课时/第N课时-<slug>.md
```

- `N` 用阿拉伯数字：第1课时、第2课时……
- 示例：`第一单元-数与代数/课时/第1课时-认识分数.md`

## 四、复盘文件（固定名）

- 单元复盘：`单元目录/单元复盘.md`
- 学期复盘：`学期课程/<学期>/学期复盘.md`

## 五、课程规则文件（固定 7 个）

```
课程规则/
├── 课程基本信息.md
├── 课程标准要点.md
├── 教材与版本说明.md
├── 学校教学要求.md
├── 学情概览.md
├── 评价与作业原则.md
└── 教学进度规则.md
```

## 六、资源库

```
资源库/课件与素材/<描述>.<ext>        # 课件、图片、视频等
资源库/作业与评价/<单元或课时>-作业.md  # 作业设计、测验、量规
资源库/优秀课例/<slug>.md             # 打磨过的完整课例
```

## 七、教研与复盘

```
教研与复盘/课堂反思/YYYYMMDD-<slug>.md   # 单课/单单元反思
教研与复盘/听评课记录/YYYYMMDD-<slug>.md # 听课记录
教研与复盘/教学问题库.md                 # 累积的问题台账（表格）
```

## 八、状态字段（写在文档 frontmatter）

单元与课时**用状态字段标记进度，不移动文件夹**：

- 单元：`status: 设计中 | 已授课 | 已复盘 | 已归档`
- 课时：`status: 备课中 | 已授课 | 已反思`

## 九、通用约定

- 正文一律 Markdown；二进制素材只放链接与说明，不内嵌。
- 不删除历史；过时内容标记状态或加 `已归档` 而非抹除。
- 同一单元的所有产物（课时、复盘、作业）都挂在单元目录下，便于整单元回看。
