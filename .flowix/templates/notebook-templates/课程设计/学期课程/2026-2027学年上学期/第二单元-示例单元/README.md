# 第二单元 — 占位说明

本目录是"单元"的标准骨架占位。请按真实学科操作：

1. 将本目录重命名为 `第N单元-<slug>`（如 `第二单元-小说单元`），规则见 `../../../项目说明/命名规范.md`。
2. 复制 `../第一单元-示例单元/` 的三件套到本目录：
   - `单元设计.md`（使用 `../../../.agents/模板/单元设计.md`）
   - `课时/第N课时-<slug>.md`（使用 `../../../.agents/模板/课时设计.md`）
   - `单元复盘.md`（使用 `../../../.agents/模板/单元复盘.md`）
3. 运行「单元整体设计」技能生成单元设计，再逐课时用「课时教学设计」技能。
4. 授课后在 `../学期课程计划.md` 的单元清单中更新本单元状态。

> 本 `README.md` 仅为占位；填充内容后可删除。
