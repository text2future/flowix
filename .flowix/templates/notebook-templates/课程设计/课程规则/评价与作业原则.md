# 评价与作业原则

> 统一作业设计与评价的标准，保证"教—学—评"一致，且符合学校要求。

## 作业设计原则

- 目标一致：作业必须对应课时 / 单元目标，不超标、不偏题。
- 分层：基础 / 提升 / 拓展三档，学困生保底、学优生吃饱。
- 量与时长：单科每日不超过 &nbsp; 分钟（见学校教学要求）。
- 类型多样：书面 + 实践 / 阅读 / 项目，避免题海。

## 评价标准（量规通用维度）

- 准确性：&lt;知识与技能正确程度&gt;
- 过程性：&lt;思路、方法、步骤&gt;
- 规范性：&lt;格式、表达、习惯&gt;
- 创新性：&lt;独到见解 / 解法&gt;

## 评价方式

- 当堂反馈：&lt;提问、板演、小测&gt;
- 课后批改：&lt;全批 / 抽批 / 互评规则&gt;
- 表现性评价：&lt;项目、展示的评分要点&gt;

## 红线

- 不布置惩罚性、重复机械作业。
- 评价不唯分数，关注素养达成。
