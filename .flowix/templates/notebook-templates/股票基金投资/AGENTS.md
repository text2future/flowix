# AGENTS.md — 股票基金投资管理 工作区代理指南

本文件面向在本工作区运行的所有 AI Agent（智能体）。它定义了工作区的目的、结构约定，以及每个技能何时、如何被调用。人类用户请优先阅读 `README.md`。

## 一、工作区定位

这是一个**个人股票 / 基金投资管理笔记本**，用一套固定目录 + 一组专职 Agent 技能，把「研究 → 决策 → 交易 → 持有 → 复盘」的全流程收敛到一个可复制、可追溯的空间里。

- 目标用户：自主管理股票 / 基金仓位的个人投资者，或替家庭 / 小账户做纪律化管理的负责人。
- 核心资产：投资规则、持仓清单、标的研究、交易计划与记录、复盘与教训。
- 协作方式：每个技能只做一件事，上游产物是下游的输入；**规则与纪律是所有技能共同遵守的标尺**。

## 三、投资管理流水线（标准顺序）

1. **标的研究** — 把观察名单 / 市场笔记里的标的，研究成 `研究与计划/标的研究/进行中/<slug>/标的研究.md`，给出「买 / 观察 / 放弃」结论。
2. **买卖前检查** — 对拟定交易跑规则 + 风险边界，产出「通过 / 驳回」与交易计划草稿。
3. **用户执行** — 交易计划移到「已执行」，记入 `交易记录.md`，更新 `持仓清单.md` / `组合总览.md`。
4. **组合检查** — 周期性（周 / 季 / 大波动后）检查组合整体是否越界。
5. **月度复盘** — 月末汇总收益、规则命中与偏离、风险事件、投资教训。

> 不是每笔都要走完 5 步。纯观察标的停在「标的研究·进行中」；已达买入条件的才进入「买卖前检查」。

## 四、文件与命名约定

- 严格遵循 `项目说明/命名规范.md`。核心规则见下：
  - 标的 slug：用代码或简称的短横线形式，如 `hs300-etf`、`kweichow-moutai`。
  - 交易计划：`交易计划/待确认/YYYYMMDD-<slug>-<买或卖>.md`。
  - 月度复盘：`复盘/月度/YYYY-MM-复盘.md`。
- 所有正文用 Markdown，便于 Agent 读写与版本管理。
- 不删除历史交易与研究；放弃 / 过时内容移入「已放弃 / 已归档」，不抹除。

## 五、Agent 协作原则

- **规则优先**：任何买卖建议都必须先过 `投资规则/投资规则.md` 与 `资金与风险边界.md`，规则是硬约束。
- **谁的输入谁负责**：调用下游技能前，先确认上游产物已就绪且路径正确。
- **只动自己职责内的文件**：标的研究不替你下单；组合检查不直接改交易计划。
- **留下可追溯的痕迹**：在对应文档的「状态 / 日志」区记录做了什么、何时做的。
- **不确定就问**：涉及真实下单等外部动作前，必须获得用户确认。
- **中文输出**：除代码、专有名词外，一律使用简体中文。
