# 术语表

> 本系统高频投资术语的统一写法与含义。起草研究 / 计划时，专有名词以本表为准，首次出现给全称。

| 术语 | 全称 / 含义 | 首次出现写法 |
| --- | --- | --- |
| ETF | 交易型开放式指数基金 | ETF（交易型开放式指数基金） |
| PE | 市盈率，价格 / 每股收益 | 市盈率（PE） |
| PB | 市净率，价格 / 每股净资产 | 市净率（PB） |
| ROE | 净资产收益率 | 净资产收益率（ROE） |
| 净值 | 基金每份单位价值 | 基金净值 |
| 跟踪误差 | 指数基金收益与标的指数的偏离 | 跟踪误差 |
| 回撤 | 从高点回落的最大幅度 | 最大回撤 |
| 定投 | 定期定额买入 | 定投（定期定额） |
| 网格 | 在价格区间分批挂单的策略 | 网格策略 |
| 仓位 | 某标的市值占账户总市值比例 | 仓位 |
| 基准 | 用于对比的组合参照（如沪深300） | 业绩基准 |
