# 组合检查

## 触发条件
- 周期：每周 / 每季例行；或用户说「检查下组合」。
- 事件：完成一笔交易后、市场单日大幅波动后。

## 输入
- `投资组合/持仓清单.md`（当前持仓）。
- `投资组合/组合总览.md`（历史快照）。
- `投资规则/投资规则.md`（仓位、行业、现金规则）。
- `投资规则/资金与风险边界.md`（红线）。

## 输出
- 更新 `投资组合/组合总览.md`（市值、收益、各维度占比、偏离项）。
- 偏离清单 + 再平衡建议（哪些越界、调多少）。

## 工作流程
1. **汇总**：从持仓清单算总市值、总成本、收益率、各标的 / 行业占比。
2. **对照**：逐项比对《投资规则》的仓位、行业、现金下限。
3. **找偏离**：列出越界维度与偏离幅度（数值化）。
4. **建议**：给出再平衡动作（卖高买低回到区间），注明是否触发强制项。
5. **更新**：把本次快照写入组合总览的「检查日志」。

## 质量清单
- [ ] 数据取自持仓清单，非凭记忆
- [ ] 偏离项有具体数值与阈值
- [ ] 再平衡建议可执行（具体到标的与金额）

## 衔接
- 上游：买卖前检查 / 交易执行
- 下游：月度复盘（汇总到复盘/月度）；必要时回到交易计划
