# 标的研究

## 触发条件
- `投资组合/观察名单.md` 或 `资料/市场笔记/` 中有待研究标的。
- 用户说「研究一下 XX / 帮我看看这个标的」。

## 输入
- 标的线索（代码 / 名称）。
- 已有 `资料/`（基金资料、公司与行业、术语表）。
- `投资规则/投资规则.md`（筛选标准）。

## 输出
- `研究与计划/标的研究/进行中/<slug>/标的研究.md`（套用 `.agents/模板/标的研究.md`）。
- 可选：把可复用资料沉淀到 `资料/基金资料/` 或 `资料/公司与行业/`。

## 工作流程
1. **建目录**：在 `进行中/` 下建 `<slug>/`，拷贝模板到 `标的研究.md`。
2. **填模板**：按六段（生意 / 质量 / 估值 / 风险 / 结论）逐项填，事实与观点分开。
3. **给结论**：明确「买 / 观察 / 放弃」及触发条件；观察类不进入交易计划。
4. **沉淀**：高价值资料归到 `资料/` 对应目录，研究文档内引用。
5. **标状态**：顶部「状态」随结论更新（观察 = 进行中；买 = 可进交易计划）。

## 质量清单
- [ ] 每个结论都有数据 / 来源支撑
- [ ] 明确区分「事实」与「我的判断」
- [ ] 风险段非空（必须写最大风险）
- [ ] 结论可执行（买 / 观察 / 放弃明确）

## 衔接
- 上游：观察名单 / 市场笔记
- 下游：买卖前检查（结论为「买」时）
- 状态流转：进行中 → 已持有（买入后）/ 已放弃（放弃）/ 已归档（过时）
