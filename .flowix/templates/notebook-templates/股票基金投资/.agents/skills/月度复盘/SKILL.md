# 月度复盘

## 触发条件
- 月末（自然月最后几天或次月初）。
- 用户说「做一下月度复盘 / 这个月投资怎么样」。

## 输入
- `投资组合/交易记录.md`（当月交易）。
- `投资组合/组合总览.md`（月末快照）。
- `复盘/风险事件.md`、`复盘/投资教训.md`。
- `投资规则/投资规则.md`（对照偏离）。

## 输出
- `复盘/月度/YYYY-MM-复盘.md`（套用 `.agents/模板/月度复盘.md`）。
- 更新的教训 / 风险事件（追加到对应文档）。

## 工作流程
1. **汇总**：拉当月交易记录，统计买卖次数、关键操作。
2. **归因**：算收益，找贡献最大 / 拖累最大的标的，解释跑赢 / 跑输基准原因。
3. **规则体检**：对照《投资规则》看本月命中与偏离（有没有违规、有没有擦边）。
4. **风险与教训**：把当月风险事件与可迁移教训固化到 `复盘/` 对应文档。
5. **下月计划**：列再平衡动作、要推进的研究、进观察名单的标的。

## 质量清单
- [ ] 数据有交易记录支撑，非估算
- [ ] 教训可迁移（不只是「下次注意」）
- [ ] 链接到具体交易 / 风险事件，可追溯

## 衔接
- 上游：组合检查（本月末快照）
- 下游：年度复盘（年终汇总）；规则修订（如需调整纪律）
