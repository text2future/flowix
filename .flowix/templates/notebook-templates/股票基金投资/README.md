# 股票基金投资管理 · 工作区使用手册

> 一个用笔记管理个人股票 / 基金投资全流程的系统：从标的研究、买卖决策，到持仓跟踪与月度复盘，都由一组专职 Agent 技能协作完成。

## 这是什么

你面前是一套**可复制的投资管理项目模板**。它把投资从「凭感觉买卖、事后想不起来为什么买」变成一条有纪律、可追溯、能交给 AI 协作的流水线。

本模板位于 `notebook-template/股票基金投资管理/`，是 `notebook-template/` 下的**第二个项目模板**。未来每个新项目（如「加密资产」「房产投资」）都可以在 `notebook-template/` 下新建同级目录。

## 三分钟上手

1. **先定规则** → 在 `投资规则/投资规则.md` 写下你的投资纪律与红线；在 `资金与风险边界.md` 设定仓位上限、现金下限、单笔上限。
2. **看到好标的** → 丢进 `投资组合/观察名单.md`，或 `资料/市场笔记/` 记一笔。
3. **认真研究** → 用「标的研究」技能，在 `研究与计划/标的研究/进行中/<slug>/` 下生成 `标的研究.md`，给结论。
4. **要交易了** → 用「买卖前检查」技能，先跑规则，再在 `研究与计划/交易计划/` 下建计划。
5. **执行 + 复盘** → 成交后更新 `投资组合/` 三件套；月末用「月度复盘」技能归档。

## 目录导览

- `投资规则/` — 投资纪律、资金与风险边界（决策的标尺）
- `投资组合/` — 组合总览、持仓清单、观察名单、交易记录
- `研究与计划/` — 标的研究、交易计划（含状态子目录）
- `复盘/` — 月度 / 年度复盘、风险事件、投资教训
- `资料/` — 基金资料、公司与行业、市场笔记、术语表
- `.agents/` — 4 个投资技能 + 4 个模板（系统的「发动机」）
- `项目说明/` — 使用说明、命名规范
