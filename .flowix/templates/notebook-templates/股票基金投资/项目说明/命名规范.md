# 命名规范

> 统一命名是这套系统能「被 Agent 顺畅读写」的前提。请严格遵守。

## 一、通用规则

- 一律使用**小写字母、数字、连字符 `-`**；分类桶可用中文目录名，具体条目用 slug。
- 日期格式：交易 / 复盘用 `YYYY-MM-DD` 或 `YYYYMMDD`；月份用 `YYYY-MM`。
- Markdown 文件扩展名统一为 `.md`。
- 不使用特殊字符：`\ / : * ? " < > |`。

## 二、标的 slug

- 每个被研究的标的用一个 `<slug>` 作为目录与文件标识。
- 规则：代码或简称的短横线小写形式。
  - 示例：沪深 300 ETF → `hs300-etf`；贵州茅台 → `kweichow-moutai`；某主动基金 → `fund-xxxxxx`。
- 标的研究目录：`研究与计划/标的研究/<状态>/<slug>/`，内部必有 `标的研究.md`。

## 三、投资规则与风险边界

- `投资规则/投资规则.md` — 全站唯一的纪律标尺，文件名固定。
- `投资规则/资金与风险边界.md` — 资金口径与红线，文件名固定。

## 四、投资组合

- 组合总览：`投资组合/组合总览.md`（单文件，持续更新）。
- 持仓清单：`投资组合/持仓清单.md`（单文件，表格化）。
- 观察名单：`投资组合/观察名单.md`（单文件）。
- 交易记录：`投资组合/交易记录.md`（按时间追加，不删）。

## 五、交易计划

- 路径：`研究与计划/交易计划/<状态>/YYYYMMDD-<slug>-<买或卖>.md`
  - `<状态>`：待确认 / 已执行 / 已取消
  - `<买或卖>`：`buy` / `sell`
  - 示例：`待确认/20260924-hs300-etf-buy.md`
- 执行后整文件移动到 `已执行/`；放弃则移动到 `已取消/`。

## 六、复盘

- 月度：`复盘/月度/YYYY-MM-复盘.md`
- 年度：`复盘/年度/YYYY-复盘.md`
- 风险事件：`复盘/风险事件.md`（按事件追加）
- 投资教训：`复盘/投资教训.md`（按条追加）

## 七、资料

- 基金资料：`资料/基金资料/<slug>.md`
- 公司与行业：`资料/公司与行业/<名称>.md`
- 市场笔记：`资料/市场笔记/YYYY-MM-笔记.md`
- 术语表：`资料/术语表.md`

## 八、状态标记

- 文件顶部「状态」字段表达进度：`进行中 / 已持有 / 已放弃 / 已归档`（研究）；`待确认 / 已执行 / 已取消`（交易计划）。
- 弃用内容移入对应「已放弃 / 已归档 / 已取消」，不删除。
