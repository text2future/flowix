## 推进本主题

本主题流程：主题确定 → 拍摄计划 → 拍摄选片 → 修图授权 → 编排展示。

1. **主题确定**：明确作品想表达什么及展示用途。
2. **拍摄计划**：列出地点、时间、画面清单与拍摄许可。
3. **拍摄选片**：按计划拍摄并备份，按画面作用选片而非只按技术清晰度。
4. **修图授权**：记录编辑版本、人物及场地使用授权。
5. **编排展示**：按叙事编排作品与图注，检查展示效果再发布。

- 任务入口：`进度视图.csv`。按事项ID查找记录，展示给用户时使用任务名称。
- 决策与依据：`拍摄/计划表.csv`、`拍摄/资料/资料清单.csv`。
- 新任务：复制 `公共/作品单元记录.md`，在 `作品/` 下用可读的任务名称建目录；场次、批次等重复任务加日期。
- 填写案例与真实任务时沿用空白模板的标题和字段，不另造一套简化结构。字段不适用写明原因；资料缺失时说明缺口及影响。过程写已发生的动作，产物保存到任务目录并登记实际路径。
- 结果写入 `数据/作品展示.csv`，沿用同一事项ID。检查字段单位、时间范围和对象粒度；单次任务不填项目累计数。缺失值不得用0代替。
- 本主题完成条件：肖像、场地及作品使用权核对。先逐项核对模板中的审核字段，再更新状态；缺少影响验收的证据时保持待确认。

## 本库中的教学记录

`作品/街角面包店选片编排/任务记录.md` 与 `作品/街角面包店选片编排/面包店拍摄编排.md` 展示一次任务的记录及产物。其中人物和数据为模拟；未经用户要求，不把模拟数据当作真实事实或继续虚构实际结果。外部发布、支付和联系按用户授权执行。

数据记录先确认一行代表什么对象、哪段时间与什么单位。原始记录、分类合计和项目汇总分别维护；验收表的期望结果必须与实际结果逐项对应，不能只填写“通过”。
