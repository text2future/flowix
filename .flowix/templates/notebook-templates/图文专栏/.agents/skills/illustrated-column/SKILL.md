## 推进本主题

本主题流程：专栏定位 → 选题资料 → 图文制作 → 审校发布 → 系列复盘。

1. **专栏定位**：确定系列关注的问题、读者和更新节奏。
2. **选题资料**：围绕单篇问题准备资料，标记事实与个人观察。
3. **图文制作**：使每段文字与图像说明对应，保留引用和素材来源。
4. **审校发布**：核对标题、图注、事实与版权，再登记发布版本。
5. **系列复盘**：比较系列内同口径反馈，决定延续或调整主题。

- 任务入口：`进度视图.csv`。按事项ID查找记录，展示给用户时使用任务名称。
- 决策与依据：`专栏/计划表.csv`、`专栏/资料/资料清单.csv`。
- 新任务：复制 `公共/单篇图文制作单.md`，在 `创作/` 下用可读的任务名称建目录；场次、批次等重复任务加日期。
- 填写案例与真实任务时沿用空白模板的标题和字段，不另造一套简化结构。字段不适用写明原因；资料缺失时说明缺口及影响。过程写已发生的动作，产物保存到任务目录并登记实际路径。
- 结果写入 `数据/专栏表现.csv`，沿用同一事项ID。检查字段单位、时间范围和对象粒度；单次任务不填项目累计数。缺失值不得用0代替。
- 本主题完成条件：事实、图片授权与图文对应检查。先逐项核对模板中的审核字段，再更新状态；缺少影响验收的证据时保持待确认。

## 本库中的教学记录

`创作/行道树秋季变化图文/任务记录.md` 与 `创作/行道树秋季变化图文/秋天的行道树正文.md` 展示一次任务的记录及产物。其中人物和数据为模拟；未经用户要求，不把模拟数据当作真实事实或继续虚构实际结果。外部发布、支付和联系按用户授权执行。

数据记录先确认一行代表什么对象、哪段时间与什么单位。原始记录、分类合计和项目汇总分别维护；验收表的期望结果必须与实际结果逐项对应，不能只填写“通过”。

## 接续任务

第二项教学任务为 `创作/同一路口雨后观察/任务记录.md`。从前序反馈提取下一步，先建立新ID与计划行，再填写同一公共模板；复用数据不重复登记。更新视图前核对产物存在、审核结论与状态一致。
