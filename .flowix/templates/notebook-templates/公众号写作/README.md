# 公众号写作 · 工作区使用手册

> 一个用笔记管理公众号写作全流程的系统：从灵感收集到发布复盘，都由一组专职 Agent 技能协作完成。

## 这是什么

你面前是一套**可复制的公众号写作项目模板**。它把写作从「打开文档硬写」变成一条有结构、可复用、能交给 AI 协作的流水线。

本模板位于 `notebook-template/公众号写作/`，是 `notebook-template/` 下的**第一个项目模板**。未来每个新项目（如「视频号脚本」「newsletter」）都可以在 `notebook-template/` 下新建同级目录。

## 三分钟上手

1. **有灵感了** → 丢进 `收件箱/灵感/` 或 `收件箱/链接与摘录/`，零门槛，先记下来再说。
2. **想写某篇** → 在 `选题与策划/选题池.md` 建卡，让「选题评估」技能帮你打分。
3. **开始写** → 在 `文章/写作中/` 下建 `YYYY-MM-<slug>/` 文件夹，套用 `.agents/模板/` 里的体裁模板。
4. **交给 Agent** → 按 `AGENTS.md` 的流水线，依次调用 9 个技能完成研究、写作、审校、排版、发布。
5. **发布 & 复盘** → 移入 `文章/已发布/`，在 `数据与复盘/` 记录效果。

## 目录导览

- `收件箱/` — 一切原始素材的入口（灵感 / 链接 / 读者问题 / 待整理）
- `选题与策划/` — 选题池、内容方向、专栏与系列
- `文章/` — 写作中 / 待发布 / 已发布 / 已归档
- `知识库/` — 写作规则与风格、术语表、主题资料、来源、优秀文章拆解
- `素材库/` — 封面、通用配图、截图、模板
- `数据与复盘/` — 文章复盘、公众号数据
- `.agents/` — 9 个写作技能 + 6 个体裁模板（这是系统的「发动机」）
- `项目说明/` — 本项目的背景与边界说明

## 关键文档

| 文档 | 作用 |
| --- | --- |
| `AGENTS.md` | Agent 如何在本工作区协作 |
| `命名规范.md` | 文件 / 文件夹命名规则 |
| `公众号发布规范.md` | 发布前的终检清单与排版规范 |
| `知识库/写作规则与风格.md` | 你的语气、人设、禁区 |

## 给 Agent 的一句话

读 `AGENTS.md`，然后按流水线干活；不确定是否要对外发布时，先问人。
