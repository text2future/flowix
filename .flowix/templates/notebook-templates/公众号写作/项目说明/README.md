# 项目说明

本目录说明「公众号写作」这个项目模板**为什么存在、边界在哪**。

## 背景

写作最难的不是「写」，而是把灵感、资料、草稿、排版、发布、复盘散落各处后还能拼回来。本项目模板用一套固定目录 + 一组 Agent 技能，把全流程收敛到一个可复制的笔记空间里。

## 目标用户画像

- 产品 / 设计 / 远程协作团队的内容负责人
- 关注效率工具、AI、SaaS 的从业者
- 想稳定输出、又不想被工具拖累的个人创作者

## 内容定位

- 主线：工具方法论（AI Agent、效率、写作系统）
- 辅线：产品 / 设计踩坑、远程协作、个人成长
- 体裁：技术教程、经验复盘、观点文章、项目发布

## 边界（不做什么）

- 不承接纯搬运 / 洗稿。
- 不追求日更；重质量与可复用。
- 不在此系统外维护「另一个真相版本」。

## 模板维护

- 技能逻辑变更 → 改 `.agents/skills/*/SKILL.md`。
- 体裁变化 → 改 `.agents/模板/*.md`。
- 规范变化 → 改根目录 `命名规范.md` / `公众号发布规范.md`。
