# 公众号发布规范

> 发布前的最终标准。发布是不可逆的外部动作，务必逐项确认。

## 一、发布前终检清单（发布准备技能执行）

- [ ] 标题：≤ 30 字，有钩子、无标题党、无错别字
- [ ] 摘要：≤ 120 字，能独立成立、引发好奇
- [ ] 正文：结构审校 + 事实核查均通过，无遗留 `⚠️待核实`
- [ ] 排版：符合下方「排版规范」，手机端阅读无压迫感
- [ ] 封面：`素材库/封面/<slug>-cover.png`，尺寸 900×383（2.35:1），重点居中
- [ ] 标签 / 话题：2–3 个，命中主关键词
- [ ] 原创声明：开启（如适用）
- [ ] 互动钩子：文末有「引导关注 + 往期回顾 + 留言引导」
- [ ] 合规：无夸大、无诱导分享、无未授权引用

## 二、排版规范（公众号排版技能执行）

- **字号**：正文 15–16px；标题 18–20px。
- **行距**：1.75–2.0 倍，段间距 ≥ 1 行。
- **段落**：移动端单段 ≤ 5 行，长文多分段。
- **强调**：重点句加粗即可，避免全文高亮；金句可单独成段。
- **小标题**：用 `##` / `###`，每 300–500 字出现一次，带序号更佳。
- **列表**：步骤、要点用有序 / 无序列表。
- **引导关注**：文末固定模块（见模板「文章.md」尾部）。
- **往期回顾**：链接 2–3 篇相关旧文（用「旧文检索与更新」技能找）。

## 三、发布节奏建议

- 固定栏目固定时间（如每周三 / 周日 20:00）。
- 系列文连续发布，间隔 ≤ 7 天。
- 热点文 24h 内出，错过时效移回选题池。

## 四、发布后动作

1. 文章移入 `文章/已发布/2026/`。
2. 在 `数据与复盘/文章复盘.md` 建卡，记录发布日期、选题来源、预期目标。
3. 数据回采：发布 3 / 7 / 30 天后填入 `数据与复盘/公众号数据/YYYY-MM-数据.md`。
4. 触发「旧文检索与更新」，互链相关新 / 旧文。
