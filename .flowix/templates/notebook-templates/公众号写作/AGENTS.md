# AGENTS.md — 公众号写作 工作区代理指南

本文件面向在本工作区中运行的所有 AI Agent（智能体）。它定义了工作区的目的、结构约定，以及每个技能何时、如何被调用。人类用户请优先阅读 `README.md`。

## 一、工作区定位

这是一个**个人公众号写作管理系统**，用笔记（notebook）的形式把「灵感 → 选题 → 研究 → 写作 → 审校 → 发布 → 复盘」的全流程沉淀下来，并交由一组专职 Agent 技能协作完成。

- 目标读者：产品 / 设计 / 远程协作类团队，以及关注效率与 AI 工具的从业者。
- 核心资产：文章草稿、选题池、知识库、素材库、复盘数据。
- 协作方式：每个技能只做一件事，上游技能的产物是下游技能的输入。

## 二、目录结构与职责映射

| 目录 | 职责 | 主要协作技能 |
| --- | --- | --- |
| `收件箱/` | 零门槛收集（灵感、链接、读者问题、待整理） | 灵感整理 |
| `选题与策划/` | 选题池、内容方向、专栏系列 | 选题评估 |
| `文章/写作中/` | 单篇文章工作区（文章.md + 资料与备注.md + 素材/） | 资料研究 / 大纲与写作 / 结构审校 / 事实核查 / 公众号排版 / 发布准备 |
| `文章/待发布/` | 已写好、等待排期发布 | 发布准备 |
| `文章/已发布/` | 按年份归档的已发布文章 | 旧文检索与更新 |
| `文章/已归档/` | 不再维护或过时的内容 | — |
| `知识库/` | 写作规则、术语表、主题资料、来源、优秀拆解 | 资料研究 / 事实核查 |
| `素材库/` | 封面、通用配图、截图、模板 | 公众号排版 |
| `数据与复盘/` | 单篇复盘 + 公众号数据 | 旧文检索与更新 |

## 三、写作流水线（标准顺序）

1. **灵感整理** — 把 `收件箱/` 的碎片提炼成结构化选题卡，写入 `选题与策划/选题池.md`。
2. **选题评估** — 对选题打分，决定 go / no-go；通过的进入 `文章/写作中/<slug>/`。
3. **资料研究** — 为通过选题收集来源与资料，产出 `资料与备注.md`。
4. **大纲与写作** — 套用 `.agents/模板/` 中对应体裁模板，产出 `文章.md` 初稿。
5. **结构审校** — 检查结构、逻辑、可读性，给出修改清单。
6. **事实核查** — 核实数据、引用、专有名词，标注待核实项。
7. **公众号排版** — 按 `公众号发布规范.md` 做微信友好排版。
8. **发布准备** — 终检 + 封面 + 摘要 + 标签，移入 `文章/待发布/`。
9. **发布后** — 移动到 `文章/已发布/2026/`，并在 `数据与复盘/` 记录。
10. **旧文检索与更新** — 周期性检索 evergreen 内容，决定是否刷新或互链。

> 不是每篇都要走完 10 步。短观点文可跳过资料研究；系列文要回到选题与策划的专栏规划。

## 四、文件与命名约定

- 严格遵循根目录 `命名规范.md`。核心规则：单篇文章目录用 `YYYY-MM-<slug>` 命名；草稿文件统一小写 `.md`。
- 所有正文用 Markdown 编写，便于 Agent 读写与版本管理。
- 不删除已发布文章；过时内容移入 `已归档/`。

## 五、Agent 协作原则

- **谁的输入谁负责**：调用下游技能前，先确认上游产物已就绪且路径正确。
- **只动自己职责内的文件**：灵感整理不要直接改文章；排版不要改事实。
- **留下可追溯的痕迹**：在对应文档的「状态 / 日志」区记录做了什么、何时做的。
- **不确定就问**：涉及发布等外部动作前，必须获得用户确认。
- **中文输出**：除代码、专有名词外，一律使用简体中文。
