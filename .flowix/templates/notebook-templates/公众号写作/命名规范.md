# 命名规范

> 统一命名是这套系统能「被 Agent 顺畅读写」的前提。请严格遵守。

## 一、通用规则

- 一律使用**小写字母、数字、连字符 `-`**；分类桶可用中文目录名，具体条目用 slug。
- 日期格式固定 `YYYY-MM-DD`（如 `2026-09-24`）。
- Markdown 文件扩展名统一为 `.md`。
- 不使用特殊字符：`\ / : * ? " < > |`。

## 二、单篇文章目录

路径：`文章/写作中/YYYY-MM-<slug>/`

- `YYYY-MM`：计划动笔的年月。
- `<slug>`：英文或半角小写短横线连接的文章主题，≤ 40 字符。
  - 示例：`2026-09-ai-agent-writing`、`2026-10-saas-onboarding`。
- 目录内固定三件套：
  - `文章.md` — 正文
  - `资料与备注.md` — 研究笔记与引用
  - `素材/` — 本文用到的图片、截图
- **全生命周期共用同一目录**：这篇目录在流转中不被拆开。`写作中 → 待发布 → 已发布/年份 → 已归档` 是**移动整个目录**，三件套始终在一起。切勿只提走 `文章.md` 而丢掉资料与素材——否则复盘与旧文检索将找不到原始依据。

## 三、选题与策划

- `选题池.md` 内每条选题用二级标题 `## <选题短名>`。
- 专栏 / 系列用 `专栏与系列.md` 集中管理，系列内文章 slug 加统一前缀（如 `series-growth-01`）。

## 四、知识库

- 主题资料：`知识库/主题资料/<主题名>/`，内部放该主题的归集文档。
- 来源：`知识库/来源/<来源名>-<日期>.md`，记录一条出处（标题 / 链接 / 关键结论 / 引用格式）。

## 五、素材库

- 封面：`素材库/封面/<slug>-cover.png`。
- 配图：`素材库/通用配图/<用途>-<序号>.png`。
- 截图：`素材库/截图/<文章slug>-<描述>.png`。

## 六、数据与复盘

- 单篇复盘：在 `数据与复盘/文章复盘.md` 内以 `## <slug>` 追加，不用单独文件。
- 公众号数据：按月在 `数据与复盘/公众号数据/` 下建 `YYYY-MM-数据.md`。

## 七、版本与状态标记

- 文件名或文档顶部「状态」字段表达进度：`灵感 / 选题中 / 写作中 / 审校中 / 待发布 / 已发布 / 已归档`。
- 弃用内容移入 `文章/已归档/`，不删除。
