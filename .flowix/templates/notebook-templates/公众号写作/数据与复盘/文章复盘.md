# 文章复盘

> 每发一篇，在此以 `## <slug>` 追加一张复盘卡。这是内容迭代的「数据库」。

## 复盘卡模板

```plaintext
## <slug> — <标题>
- 发布日期：YYYY-MM-DD
- 选题来源：选题池 / <slug>
- 体裁：技术教程 / 经验复盘 / 观点文章 / 项目发布
- 预期目标：<写这篇想达成什么>
### 数据（发布后回填）
- 阅读： / 完读率： / 分享： / 涨粉：
- 数据快照日：发布后 3d / 7d / 30d
### 做得好的
- 
### 待改进的
- 
### 对下一篇的启示
- 
```

## 复盘记录

（空。第一篇文章发布后在此建卡，长期积累成「什么体裁 / 什么选题有效」的判断依据。）
