# 公众号排版

## 触发条件
- `文章.md` 无遗留 `⚠️待核实`，结构审校通过。
- 用户说「帮我排版 / 适配公众号」。

## 输入
- 通过审校的 `文章.md`
- `公众号发布规范.md` 的排版规范

## 输出
- 排版后的 `文章.md`（含 H2 序号、强调、列表、文末模块、分段优化）。

## 工作流程
1. **标题层级**：统一 `##` / `###`，长文加「01 / 02」序号。
2. **分段**：移动端单段 ≤ 5 行，长段拆分。
3. **强调**：核心句加粗；金句单独成段不加粗。
4. **列表化**：步骤、并列点用有序 / 无序列表。
5. **文末模块**：补全「引导关注 + 往期回顾 + 留言引导」（见模板）。
6. **预览自检**：模拟手机宽度，检查是否拥挤。

## 排版禁区（来自发布规范）
- 不全文高亮、不大段彩色背景。
- 不用过小字号（< 14px）。
- 不堆砌表情符号。

## 质量清单
- [ ] 符合 `公众号发布规范.md` 排版规范
- [ ] 文末三模块齐全
- [ ] 手机端阅读节奏舒适
