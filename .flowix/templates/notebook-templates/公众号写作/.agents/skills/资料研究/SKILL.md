# 资料研究

## 触发条件
- `文章/写作中/<slug>/` 已建立，但 `资料与备注.md` 为空或待补。
- 用户说「帮我找这篇的素材 / 资料」。

## 输入
- 选题陈述（来自选题池 / 文章.md 顶部）。
- 已有 `知识库/主题资料/`、读者问题中的线索。

## 输出
- `文章/写作中/<slug>/资料与备注.md`：结构化研究笔记。
- 必要时向 `知识库/来源/` 沉淀可复用来源。

## 工作流程
1. **拆问题**：把选题拆成 3–5 个需要证据支撑的子命题。
2. **找来源**：对每个子命题检索 / 回忆可靠来源（官方文档、论文、数据报告、一手案例）。
3. **记录**：按下方模板写入「资料与备注.md」，每条带来源、结论、可直接引用的原句。
4. **沉淀**：高价值、可复用的来源整理进 `知识库/来源/<来源名>-<日期>.md`。
5. **标缺口**：明确写出「还缺什么证据」，交给事实核查或用户补充。

## 资料与备注模板
```
# 资料与备注 — <slug>
## 子命题1：<陈述>
- 来源：[名称](链接) — 关键结论 / 可引原句
## 待补充
- <还缺的证据>
```

## 质量清单
- [ ] 每个子命题至少 1 个可引用来源
- [ ] 来源注明出处与日期，便于事实核查
- [ ] 区分「事实」与「我的解读」
- [ ] 明确标注证据缺口

## 衔接
- 上游：选题评估
- 下游：大纲与写作 / 事实核查
