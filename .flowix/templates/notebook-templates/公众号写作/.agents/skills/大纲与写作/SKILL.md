# 大纲与写作

## 触发条件
- `文章/写作中/<slug>/` 已建，且 `资料与备注.md` 中无「还缺关键证据」阻塞项。
- 用户说「帮我写大纲 / 起草这篇」。

## 输入
- `资料与备注.md`（论据池）
- `.agents/模板/` 中匹配的体裁模板（文章 / 技术教程 / 经验复盘 / 观点文章 / 项目发布）
- `知识库/写作规则与风格.md`（语气与人设约束）

## 输出
- `文章/写作中/<slug>/文章.md` 初稿（含标题、摘要、正文、文末模块）。

## 工作流程
1. **选模板**：按体裁从 `.agents/模板/` 拷贝对应模板到 `文章.md`。
2. **搭骨架**：先写大纲（H2 层级 + 每节一句话论点），给用户确认再展开。
3. **填血肉**：依据资料与备注逐节成文，金句单独成段。
4. **写钩子**：标题与开头 100 字决定打开率，单独打磨。
5. **文末模块**：补全「引导关注 / 往期回顾 / 留言引导」。
6. **自检**：对照 `写作规则与风格.md` 检查语气、禁区、术语一致性。

## 质量清单
- [ ] 大纲已确认（或用户授权直接写）
- [ ] 每个论点都有资料支撑
- [ ] 开头有钩子、结尾有行动召唤
- [ ] 术语与 `术语表.md` 一致
- [ ] 无 `写作规则与风格.md` 列明的禁区表达

## 衔接
- 上游：资料研究
- 下游：结构审校 → 事实核查 → 公众号排版
