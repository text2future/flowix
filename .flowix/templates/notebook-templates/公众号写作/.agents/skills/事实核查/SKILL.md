# 事实核查

## 触发条件
- `文章.md` 结构审校通过后，发布前必经。
- 用户说「帮我核查一下事实 / 数据」。

## 输入
- `文章.md` 全文
- `资料与备注.md` 中的来源记录
- `知识库/来源/`、`术语表.md`

## 输出
- 核查报告：逐条「✅ 已核实 / ⚠️ 待核实 / ❌ 有误」。
- 在 `文章.md` 中对无法核实处插入 `⚠️待核实` 标记。

## 核查对象
- 数字：百分比、年份、价格、统计口径。
- 引用：谁说的、原话是否准确、上下文是否被曲解。
- 专有名词：产品名、公司名、技术术语拼写与含义。
- 因果：是否把相关当因果、是否过度概括。

## 工作流程
1. 抽取文中所有「可证伪陈述」。
2. 对照来源逐条验证，记录验证方式与日期。
3. 无法验证的标 `⚠️待核实`，不删除，交给用户决定。
4. 输出报告，明确「可否发布」。

## 质量清单
- [ ] 所有数字都有出处
- [ ] 引用未脱离原意
- [ ] 无 `⚠️待核实` 残留时才允许进入排版
