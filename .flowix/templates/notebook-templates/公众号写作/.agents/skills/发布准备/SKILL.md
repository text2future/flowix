# 发布准备

## 触发条件
- 排版后的 `文章.md` 就绪，准备排期发布。
- 用户说「准备发布这篇」。

## 输入
- 排版后的 `文章.md`
- `公众号发布规范.md` 终检清单
- `素材库/封面/`（需有封面图）

## 输出
- 终检结论（通过 / 阻塞项）。
- 摘要（≤ 120 字）、标签（2–3 个）。
- 把整篇目录 `文章/写作中/<slug>/` 移动至 `文章/待发布/<slug>/`（三件套一起带走，不拆分）。

## 工作流程
1. **跑终检**：逐条核对 `公众号发布规范.md` 的发布前清单。
2. **写摘要**：提炼一句能独立成立、引发好奇的摘要。
3. **定标签**：2–3 个命中主关键词的话题。
4. **封面**：确认 `素材库/封面/<slug>-cover.png` 存在且合规（900×383）。
5. **归档**：移入 `文章/待发布/`，在选题池把状态改为「待发布」。
6. **阻塞处理**：若有未过项，列清单交用户，不擅自发布。

## 质量清单
- [ ] 终检全绿
- [ ] 摘要 / 标签 / 封面三件套齐全
- [ ] 未获用户确认前不执行任何对外发布动作

## 衔接
- 上游：公众号排版
- 下游：（用户发布后）旧文检索与更新 / 数据与复盘
