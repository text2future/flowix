# 灵感整理

## 触发条件
- 用户在 `收件箱/灵感/`、`收件箱/链接与摘录/`、`收件箱/读者问题/`、`收件箱/待整理/` 放入新内容。
- 用户说「帮我整理一下灵感 / 收件箱」。

## 输入
- `收件箱/` 下的任意原始条目（一句话、链接、截图文字、读者提问）。

## 输出
- 写入 `选题与策划/选题池.md` 的结构化选题卡。
- 原条目标记已处理（顶部加 `状态: 已提炼` 或移动到对应归档）。

## 工作流程
1. **扫描**：列出 `收件箱/` 各子目录中未处理的条目。
2. **归类**：判断每条属于 灵感 / 素材 / 读者需求 / 噪音。
3. **提炼**：把碎片改写成一句「可被评估的选题陈述」（谁 + 什么痛点 + 什么角度）。
4. **建卡**：在 `选题池.md` 按模板追加 `## <选题短名>`，填入 来源、一句话描述、初步体裁、热度直觉。
5. **清理**：原条目标注已提炼，避免重复处理。

## 选题卡模板（写入选题池）
```
## <选题短名>
- 来源：收件箱/灵感/xxx
- 一句话：<可被评估的选题陈述>
- 初步体裁：技术教程 / 经验复盘 / 观点文章 / 项目发布
- 热度直觉：高 / 中 / 低
- 状态：灵感
```

## 质量清单
- [ ] 每条原始素材都有去处（选题卡 or 直接丢弃并说明）
- [ ] 选题陈述聚焦「给读者什么价值」，而非「我想写什么」
- [ ] 不杜撰原条目没有的信息

## 衔接
- 下游：选题评估（对选题池中的「灵感」状态条目打分）
