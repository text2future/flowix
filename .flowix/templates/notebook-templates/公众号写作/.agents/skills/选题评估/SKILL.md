# 选题评估

## 触发条件
- `选题池.md` 中状态为「灵感 / 选题中」的条目。
- 用户问「这个选题值不值得写」。

## 输入
- `选题与策划/选题池.md` 中的候选选题。
- 可选：`内容方向.md`（判断是否与主线一致）、`知识库/` 已有资料。

## 输出
- 每个选题的评分表 + go / no-go 结论。
- 通过的选题：在 `文章/写作中/` 建 `YYYY-MM-<slug>/` 目录（含 `素材/` 子目录），并把选题卡状态改为「写作中」。

## 五维评分（每项 1–5 分）
| 维度 | 问题 |
| --- | --- |
| 读者价值 | 读完能解决一个真实问题或获得新认知吗？ |
| 需求强度 | 目标读者此刻是否迫切需要？ |
| 差异化 | 和市面已有内容比，新角度 / 新证据 / 新体验？ |
| 可行性 | 我是否有素材、案例、数据支撑？ |
| 时效性 | 是 evergreen 还是窗口期很短？ |

- **总分 ≥ 18 且可行性 ≥ 4** → go。
- **12–17** → 可写但需补素材，标「选题中·待补」。
- **< 12** → no-go，移回灵感或丢弃并备注原因。

## 工作流程
1. 拉取待评估选题。
2. 逐项打分，写一句「为什么这个分数」。
3. 给出结论与建议体裁。
4. go 的：建目录、分配 slug、更新状态、在 `内容方向.md` 标注归属。
5. no-go 的：写清原因，避免日后重复评估。

## 质量清单
- [ ] 每个维度都有理由，不是拍脑袋
- [ ] 与 `内容方向.md` 的主线对齐校验过
- [ ] 通过的选题已落地到 `文章/写作中/`

- 下游：资料研究 / 大纲与写作
