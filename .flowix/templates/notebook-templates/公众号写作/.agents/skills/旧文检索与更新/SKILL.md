# 旧文检索与更新

## 触发条件
- 新文发布后，需要互链相关旧文。
- 定期（如每月）巡检 evergreen 内容是否过时。
- 用户说「找找有没有相关的旧文 / 哪些该更新了」。

## 输入
- `文章/已发布/`、`文章/已归档/`
- 当前新文的选题与关键词
- `术语表.md`、`优秀文章拆解.md`（判断质量）

## 输出
- 相关旧文清单（用于文末「往期回顾」）。
- 过时内容清单 + 更新建议（或移入已归档的建议）。

## 工作流程
1. **关键词匹配**：用新文关键词检索 `已发布/` 标题与正文。
2. **相关性排序**：挑 2–3 篇最相关作为往期回顾。
3. **常青巡检**：扫描 evergreen 选题，对比当前事实 / 数据是否过时。
4. **更新决策**：
   - 仍准确 → 仅互链。
   - 部分过时 → 标注待更新，生成更新补丁建议。
   - 完全过时 → 建议移 `已归档/` 并注明。
5. **回写**：把互链建议交给排版 / 发布准备；把更新建议记入复盘。

## 质量清单
- [ ] 往期回顾链接真实有效
- [ ] 过时判断有依据（对比来源日期）
- [ ] 不删除已发布历史，只标记

## 衔接
- 上游：发布准备 / 数据与复盘
- 下游：大纲与写作（对需更新的旧文重启流程）
