# 考研信息核对

## 触发条件
- 用户开始备考，或要求核对院校 / 专业 / 科目 / 大纲 / 时间节点。
- 官方信息更新（招生简章、专业目录、大纲发布）时。

## 输入
- 用户提供的目标院校 / 专业 / 年份
- 官方来源（研招网、目标院校研究生院招生简章、专业目录、考试大纲）

## 输出
- `目标与规则/考研目标.md`（使用 `.agents/模板/考研目标.md`）
- `目标与规则/院校与专业信息.md`
- `目标与规则/考试科目与大纲.md`
- `目标与规则/报名与时间节点.md`
- 把关键时间节点提示给用户（报名、网上确认、初试）

## 工作流
1. 核对院校名称、学院、专业代码、招生人数、是否招收跨考 / 同等学力。
2. 核对考试科目（政治 / 外语语种 / 业务课一 / 业务课二）与对应大纲范围、题型分值。
3. 摘录报名与考试时间节点（预报名、正式报名、网上确认、初试、出分、复试、调剂）。
4. 固化到 `目标与规则/` 四个文件，标注信息来源与更新日期。
5. 提示用户：时间节点为硬约束，需与官方每年公告二次确认。

## 质量检查清单
- [ ] 院校 / 专业 / 代码 / 招生信息准确，标注来源
- [ ] 科目与大纲范围、题型分值已核对
- [ ] 关键时间节点齐全（报名 / 确认 / 初试 / 复试 / 调剂）
- [ ] 目标分数（总分 + 单科线）已记录
- [ ] 标注了信息来源与更新日期

## 上游 / 下游
- 上游：无（入口，信息变动时触发）
- 下游：`周计划制定`（依据目标与时间节点排计划）、`周复盘与计划调整`
