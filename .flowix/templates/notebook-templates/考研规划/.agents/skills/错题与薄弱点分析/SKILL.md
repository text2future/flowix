# 错题与薄弱点分析

## 触发条件
- 用户提供错题（题目、答案、错因），或要求在模考后分析。
- 上游就绪：`科目学习/<科目>/` 的练习、`错题与复盘/模考记录.md`。

## 输入
- 错题素材（题目摘要、我的答案、正确答案、错因）
- `目标与规则/考试科目与大纲.md`（知识点归属）
- 现有 `错题与复盘/错题记录.md`、`薄弱点清单.md`（避免重复造点）

## 输出
- 追加到 `错题与复盘/错题记录.md`（使用 `.agents/模板/错题记录.md` 的单卡格式）
- 更新 `错题与复盘/薄弱点清单.md`（按知识点聚类，标薄弱等级与状态）
- 把要补的点提示给「周计划制定」

## 工作流
1. 逐题记录：科目、知识点、题目摘要、错因（概念 / 计算 / 审题 / 时间）。
2. 按知识点聚类，更新薄弱点清单的频次与等级。
3. 区分"偶发错"与"系统性薄弱"，后者重点标注。
4. 给出针对性补漏动作（如重做某章、专项训练）。

## 质量检查清单
- [ ] 每题都有错因归类，不是只抄题
- [ ] 已按知识点聚类到薄弱点清单
- [ ] 已区分偶发 / 系统性薄弱
- [ ] 薄弱点带状态（未攻克 / 巩固中 / 已掌握）
- [ ] 补漏动作具体、可排进下周

## 上游 / 下游
- 上游：`科目学习`（练习）、`周计划制定`
- 下游：`周复盘与计划调整`（据薄弱点调整计划）
