# 周复盘与计划调整

## 触发条件
- 用户要求周复盘（通常周末）。
- 上游就绪：`学习计划/本周计划.md`、`错题与复盘/` 各文件已更新。

## 输入
- `学习计划/本周计划.md`（对照达成）
- `错题与复盘/错题记录.md`、`薄弱点清单.md`、`模考记录.md`
- `目标与规则/报名与时间节点.md`（剩余时间）
- `学习计划/总体计划.md`（阶段定位）

## 输出
- `错题与复盘/周复盘/YYYY-Www-周复盘.md`（使用 `.agents/模板/周复盘.md`）
- 更新 `薄弱点清单.md` 状态（哪些已攻克 / 仍薄弱）
- 调整 `学习计划/总体计划.md` 与下一周计划节奏
- 滚动未完成任务到下周

## 工作流
1. 逐科对照本周计划，看达成度与偏差。
2. 看错题趋势与薄弱点变化（变好还是恶化）。
3. 看模考分数趋势，判断阶段是否需加速 / 补基础。
4. 依据剩余时间，调整总体计划节奏（如某科超时需压缩）。
5. 产出复盘，滚动任务到下周。

## 质量检查清单
- [ ] 各科达成度有依据（完成量 / 正确率）
- [ ] 薄弱点状态已更新
- [ ] 模考趋势已纳入判断
- [ ] 调整后的计划与剩余时间、时间节点自洽
- [ ] 命名符合规范（YYYY-Www）

## 上游 / 下游
- 上游：`周计划制定`、`错题与薄弱点分析`
- 下游：下一轮 `周计划制定`、`学习计划/总体计划.md` 的修订
