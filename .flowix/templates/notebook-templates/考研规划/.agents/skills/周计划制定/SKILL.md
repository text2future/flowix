# 周计划制定

## 触发条件
- 用户要求制定本周学习计划（通常周一）。
- 上游就绪：`目标与规则/`、`学习计划/总体计划.md` 已存在。

## 输入
- `学习计划/总体计划.md`（阶段划分与各科进度）
- `目标与规则/考试科目与大纲.md`、`报名与时间节点.md`（剩余时间与节点）
- `错题与复盘/薄弱点清单.md`（要重点补的点）
- 上周 `学习计划/本周计划.md` 与最近周复盘

## 输出
- `学习计划/本周计划.md`（使用 `.agents/模板/周计划.md`，覆盖写当前周）
- 上周计划归档到 `学习计划/历史周计划/YYYY-Www-周计划.md`

## 工作流
1. 按总体计划定位本周所处阶段（基础 / 强化 / 冲刺）。
2. 分解各科本周任务量（政治 / 英语 / 数学 / 专业课），对齐剩余时间。
3. 结合薄弱点清单，为弱项加权分配时间。
4. 标注本周模考 / 关键节点。
5. 产出计划，并把上周计划归档。

## 质量检查清单
- [ ] 覆盖四科，任务量符合当前阶段与剩余时间
- [ ] 已为薄弱点加权
- [ ] 模考 / 节点已纳入
- [ ] 上周计划已归档到历史周计划
- [ ] 命名符合规范（本周计划固定名 + 历史 YYYY-Www）

## 上游 / 下游
- 上游：`考研信息核对`、`错题与薄弱点分析`
- 下游：`错题与薄弱点分析`、`周复盘与计划调整`
