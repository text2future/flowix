# AGENTS.md — 考研规划 工作区代理指南

本文件面向在本工作区运行的所有 AI Agent（智能体）。它定义了工作区的目的、结构约定，以及每个技能何时、如何被调用。人类用户请优先阅读 `README.md`。

## 一、工作区定位

这是一个**考研备考规划笔记本**，用一套固定目录 + 一组专职 Agent 技能，把「信息核对 → 总体与周计划 → 科目学习 → 错题与薄弱点分析 → 周复盘与调整」的全流程收敛到一个可复制、可追溯的空间里。

- 目标用户：正在备考研究生入学考试（考研）的考生，或陪考 / 辅导者。
- 核心资产：目标与规则（院校 / 科目 / 大纲 / 时间节点）、总体与周计划、四科学习笔记、错题与薄弱点、模考与复盘、资料索引。
- 协作方式：每个技能只做一件事，上游产物是下游的输入；**目标与规则是所有规划共同遵守的标尺**。

## 二、目录结构与职责映射

| 目录 | 职责 | 主要协作技能 |
| --- | --- | --- |
| `目标与规则/` | 考研目标、院校专业、科目大纲、时间节点（所有规划的标尺） | 考研信息核对 |
| `学习计划/` | 总体计划、本周计划、历史周计划 | 周计划制定 / 周复盘与计划调整 |

## 三、考研规划流水线（标准顺序）

1. **考研信息核对** — 核对并固化 `目标与规则/`（院校、科目、大纲、报名与考试时间节点），作为一切规划的标尺。
2. **周计划制定** — 依据 `学习计划/总体计划.md` 与 `目标与规则/`，产出 `学习计划/本周计划.md`。
3. **科目学习（人类执行）** — 按周计划在各 `科目学习/<科目>/` 下积累笔记与练习。
4. **错题与薄弱点分析** — 把练习 / 模考的错题记入 `错题与复盘/错题记录.md`，聚合到 `薄弱点清单.md`。
5. **周复盘与计划调整** — 周末做 `错题与复盘/周复盘/`，对照计划看达成，调整下周计划。

> 不是每周都要走完 5 步。信息核对只在信息变动时做；平时循环是 周计划 → 学习 → 错题分析 → 周复盘。

## 四、文件与命名约定

- 详见 `README.md` 的"命名与状态约定"。核心规则：
  - 周计划：`学习计划/本周计划.md`（当前），归档 `学习计划/历史周计划/YYYY-Www-周计划.md`。
  - 周复盘：`错题与复盘/周复盘/YYYY-Www-周复盘.md`。
  - 错题 / 模考：以表格 / 列表活在 `错题与复盘/*.md` 中，复杂错题可单独成文。
  - 科目笔记：`科目学习/<科目>/YYYY-Www-<主题>.md` 或按主题自由命名。
- 所有正文用 Markdown；不删除历史，归档而非抹除。

## 五、Agent 协作原则

- **规则优先**：任何计划 / 进度判断都必须先过 `目标与规则/`，尤其时间节点与大纲范围。
- **谁的输入谁负责**：调用下游技能前，确认上游产物已就绪且路径正确。
- **只动自己职责内的文件**：周计划不直接改错题；信息核对只核对、不替你定目标。
- **留下可追溯的痕迹**：在文档的「状态 / 日志」区记录做了什么、何时。
- **不确定就问**：涉及换学校 / 换专业 / 调整目标等外部重大决策，必须获得用户确认。
- **中文输出**：除专有名词外，一律简体中文。
