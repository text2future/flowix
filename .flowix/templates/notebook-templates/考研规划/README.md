# 考研规划笔记本 · 使用手册

欢迎使用「考研规划」笔记本。这是一套帮你把考研备考（信息、计划、学习、错题、复盘）系统化的模板，适合在职备考、应届备考或二战考生。它把"每天学什么、错在哪、进度够不够"这些焦虑，变成可查、可算、可调整的结构。

## 一、这套空间能帮你做什么

- **信息先固化**：院校、专业、科目、大纲、时间节点统一收在 `目标与规则/`，避免临考才发现考纲变了。
- **计划一层层拆**：总体计划 → 本周计划，节奏清楚。
- **四科各归各位**：政治 / 英语 / 数学 / 专业课各有目录，笔记与练习不打架。
- **错题变资产**：错题不只记，还聚合到薄弱点清单，直接指导下周计划。
- **复盘有闭环**：周末复盘 → 调整计划，越学越准。

## 二、第一次上手（5 步）

1. 先填 `目标与规则/` 四个文件——院校专业、科目大纲、时间节点、目标分数，这是所有规划的依据。
2. 在 `学习计划/总体计划.md` 写下从现在到考试的阶段划分（基础 / 强化 / 冲刺 / 模考）。
3. 每周用「周计划制定」技能生成 `学习计划/本周计划.md`。
4. 平时在 `科目学习/<科目>/` 记笔记；做错的题用「错题与薄弱点分析」记入 `错题与复盘/`。
5. 周末用「周复盘与计划调整」跑周复盘，调整下周与总体计划。

## 三、目录地图

| 区域 | 放什么 |
| --- | --- |
| `目标与规则/` | 考研目标、院校专业、科目大纲、报名与时间节点 |
| `学习计划/` | 总体计划、本周计划、历史周计划 |
| `科目学习/` | 政治 / 英语 / 数学 / 专业课 的笔记与练习 |
| `错题与复盘/` | 错题记录、薄弱点清单、周复盘、模考记录 |
| `资料/` | 官方信息、学习资料索引、经验与方法 |
| `.agents/` | 技能与模板（AI 引擎） |

## 四、命名与状态约定

**命名**
- 周计划：`学习计划/本周计划.md`（当前）；归档 `学习计划/历史周计划/YYYY-Www-周计划.md`。
- 周复盘：`错题与复盘/周复盘/YYYY-Www-周复盘.md`。
- 科目笔记：`科目学习/<科目>/YYYY-Www-<主题>.md`，或按主题自由命名。
- 错题 / 薄弱点 / 模考：以表格活在 `错题与复盘/*.md` 中；特别重要的错题可用 `模板/错题记录.md` 单卡成文。
- `YYYY-Www`：年-周次，如 `2026-W39`。

**状态**
- 周计划 / 复盘：`进行中 / 已完成`（写在文档元数据里）。
- 薄弱点：`未攻克 → 巩固中 → 已掌握`。
- 不删除历史；错题与复盘是备考最宝贵的资产，只归档不抹除。

## 五、给 AI 用的说明

- 所有 Agent 协作规范见 `AGENTS.md`。
- 四个技能在 `.agents/skills/`：考研信息核对、周计划制定、错题与薄弱点分析、周复盘与计划调整。
- 四个模板在 `.agents/模板/`：考研目标、周计划、错题记录、周复盘。

## 六、重要提醒

- `目标与规则/` 是硬约束，尤其**报名 / 初试时间节点**，错过无法补救，请务必与官方核对。
- 本模板中的示例（如"示例考生 / 某 985 计算机"）仅演示格式，请按真实情况替换。
