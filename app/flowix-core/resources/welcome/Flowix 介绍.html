02 · 内容

笔记是笔记，资料是资料

可编辑的笔记，不可编辑的原件，在同一个文件夹里各走各的路。

理解笔记

以 Markdown 保存的记忆

纯文本。人读得懂，AI 也读得懂。标题、列表、标签、属性本身就是结构， Agent 不用解析，就能读、能改、能总结。

  • AI 友好
  • 结构即语义
  • 任何编辑器可开
  • 能进 Git

理解资料

原样留在文件夹里的原件

原件不做格式转换，就那么放着。AI 需要时，自己去读里面的文字、表格和画面。

  • Word
  • Excel
  • PPT
  • PDF
  • 网页
  • 图片
  • 视频

笔记可读可改，资料只用不改格式——放在同一个文件夹里，Agent 才拿得到完整上下文。

03 · 为什么

三件事，不必再交给别人

数据在哪、Agent 怎么接、账单怎么算——这三件事，Flowix 都还给你。

01 · 安全优势

文档全部
留在本地

  • 只在本机磁盘，不上传；断网也能写、能搜。
  • 明文 Markdown，任何编辑器都打得开，没有专有格式可锁。
  • 备份交给 iCloud、OneDrive、Git；想走，拷走文件夹就行。

02 · 管理优势

任何 Agent
读写同一批文件

  • 内置 Agent，也能接 Claude Code、Codex、Hermes。
  • CLI 与 MCP：外部 Agent 读、搜、改，用的是同一批文档。
  • 产出直接写回文档；换电脑、换工具只是一次复制粘贴。

03 · 价格优势

AI 不用
再买一份

  • 不自建 AI 计费，复用你已有的 Codex / Claude 订阅。
  • 开源，能力跟着你选的模型与 Agent 一起升级。
  • 团队各接各的，不必统一采购一份 AI 套餐。

04 · 开始

三步开始

从空文件夹，到一份能用的上下文。

01

创建或注册文件夹

新建一个文件夹，或指向已有的一个。Flowix 接管里面的 Markdown。

02

写清背景与目标

背景、资料、目标、约束写进去。它就不只是一篇笔记，而是一份任务书。

03

让 Agent 接手

在文档里叫起 Agent，或用 MCP 接入你的客户端。产出，写回同一个文件夹。

进来之后两种界面随时切换：简洁记录 让屏幕上只剩正在写的这一篇，适合日记、待办、速记；文件树管理 把笔记、资料和 Agent 产出排在同一条树上，拖拽即可整理。
